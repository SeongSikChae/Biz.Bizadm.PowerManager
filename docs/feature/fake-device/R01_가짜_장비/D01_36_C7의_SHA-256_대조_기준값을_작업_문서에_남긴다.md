# D01_36 C7의 SHA-256 대조 기준값을 작업 문서에 남긴다

## 상황

spec 검토 1회차 지적 4. C7은 실제 다원 실행에서 받은 이미지를 사전 확인에서 받은 이미지와 SHA-256으로 대조하라고 했지만, 작업 문서에 사전 확인 이미지의 SHA-256이 없고 파일은 scratchpad에만 있어 지워질 수 있다(검토 의견). 기준값이 없으면 실행 시점에 대조할 수 없어 C7의 완료를 판정할 수 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C7, 작업 문서 사전 확인 절(`docs/specs/dawon-fake-device-fota-path/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_03`

## 결정

- A. 해시를 작업 문서에 적음: 사전 확인의 `_1`·`_2` 이미지 SHA-256 전체를 작업 문서 사전 확인 절에 적고, C7의 대조 기준을 "작업 문서에 적은 사전 확인 SHA-256"으로 고친다.
- 옛 기록의 결정 칸: A(사용자 선택, 2026-11-20)

## 이유

- A는 파일이 지워져도 기준값이 남아 같은 이미지를 받았는지 판정할 수 있다. B는 받은 이미지가 올바른지 확인할 기준이 사라져 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
