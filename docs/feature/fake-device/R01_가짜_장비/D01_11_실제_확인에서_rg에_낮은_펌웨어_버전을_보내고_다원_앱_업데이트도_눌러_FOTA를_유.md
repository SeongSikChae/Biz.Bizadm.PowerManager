# D01_11 실제 확인에서 rg에 낮은 펌웨어 버전을 보내고 다원 앱 업데이트도 눌러 FOTA를 유도한다

## 상황

다원이 FOTA 메시지를 보내야 받을 수 있으므로, 실제 다원 확인(C13)에서 업데이트를 어떻게 유도할지 정해야 했다. 어느 쪽이든 다원이 업데이트를 보내지 않으면 그 결과를 적는 것으로 완료한다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 무엇을·왜, C13(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. 낮은 버전 + 앱 업데이트: `rg`에 낮은 펌웨어 버전(예: `1.01.30`)을 보내 보고, 접속에 성공하면 사용자가 다원 앱에서 펌웨어 업데이트도 눌러 본다.

## 이유

- 다원이 업데이트를 내려보내는 두 경로(버전 비교, 사용자 요청)를 모두 시험해 받을 가능성이 가장 높다. B는 앱 요청 경로를 시험하지 않는다. C는 다원이 스스로 보낼 이유가 적어 받을 가능성이 낮다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 낮은 버전만: `rg`의 낮은 버전만 시험하고 앱 조작은 하지 않는다. | 위 「이유」에 함께 적힘 |
| C. 유도하지 않음: 기본 버전으로 실행해 다원이 스스로 FOTA를 보내는지만 본다. | 위 「이유」에 함께 적힘 |
