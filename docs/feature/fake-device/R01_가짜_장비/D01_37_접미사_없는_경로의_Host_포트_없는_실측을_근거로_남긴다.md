# D01_37 접미사 없는 경로의 Host 포트 없는 실측을 근거로 남긴다

## 상황

spec 검토 1회차 지적 5. "무엇을, 왜"의 "접미사 없는 경로는 Host 헤더의 포트 유무와 관계없이 404"는 포트를 넣은 경우만 시험해 근거가 부족했다(검토 의견). 이 문장을 C8에서 분석 기록에 옮기면 근거 없는 관찰이 들어간다. 지적 뒤 Host 포트 없이 요청해 404를 확인했다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 작업 문서 사전 확인 절(`docs/specs/dawon-fake-device-fota-path/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_03`

## 결정

- A. 실측을 작업 문서에 추가: "접미사 없는 경로, Host 포트 없음 → 404"를 작업 문서 사전 확인 절에 적고 spec 문장은 그대로 둔다.
- 옛 기록의 결정 칸: A(사용자 선택, 2026-11-20)

## 이유

- A는 실측이 있으니 근거만 남기면 된다. B는 확인한 사실을 버리게 되어 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
