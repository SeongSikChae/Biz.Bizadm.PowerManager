# C01 계약

속한 스펙: `R01`

## 항목

| ID | 이름 | 종류 | 상태 |
| --- | --- | --- | --- |
| `C01-I1` | 명령줄과 종료 코드 | 명령 | 반영 |
| `C01-I2` | 설정 파일(YAML) | 설정 파일 | 반영 |
| `C01-I3` | 주고받음 기록(JSONL) | 설정 파일 | 반영 |
| `C01-I4` | 콘솔 명령 | 명령 | 반영 |

## 호환 규칙

- 바꿔도 되는 것: 콘솔 출력 문구, 새 선택 설정 키, 기록의 새 필드
- 바꾸려면 결정 문서가 있어야 하는 것: 기록의 `channel`·`direction`·`kind` 값과 공통 필드, 설정 키 이름·기본값, 종료 코드 값, 콘솔 명령어. 이전 기록 파일과의 호환은 다루지 않는다.

## C01-I1 명령줄과 종료 코드

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| `--config` | 경로 | 예 | 설정 YAML |
| `--log` | 경로 | 예 | 로그 폴더 |

출력

- 종료 코드 0(정상 종료), 1(명령줄 인자 오류), 2(설정 오류), 3(실행 중 실패)

오류

| 코드 | 나는 조건 |
| --- | --- |
| 0이 아님 | 등록 실패, MQTT 거부·연결 실패·시간 초과, SUBACK 시간 초과, 다원 쪽 끊김 |

권한

- 콘솔 사용자

코드

- `src/Biz.Bizadm.PowerManager.FakeDevice.App/Program.cs`, `ExitCode.cs`

바뀔 것

- 없음

## C01-I2 설정 파일

입력

- 섹션 `Dawon`, `Device`, `Register`, `Mqtt`, `Publish`(`NotifyElement` 목록), `Fota`, `OsKms`, 기록 폴더. 키와 기본값은 `R01-R1`과 코드의 섹션 클래스, `config.example.yaml`을 따른다.

출력

- 설정의 `mqtt_key`는 OsKms로 보호된다.

오류

| 코드 | 나는 조건 |
| --- | --- |
| 종료 코드 2 | 파일 없음, mac 형식, 실행 슬롯이 1·2가 아님, `verify` 확인 서버 주소에 치환표 밖 문자, 값 형식 |

권한

- 실행하는 OS 계정

코드

- `src/Biz.Bizadm.PowerManager.FakeDevice.App/AppConfiguration.cs`(`DawonSection`, `DeviceSection`, `RegisterSection`, `MqttSection`, `PublishSection`, `NotifyElementSection`, `FotaSection`, `OsKmsSection`), `FakeDeviceOptions.cs`, `config.example.yaml`

바뀔 것

## C01-I3 주고받음 기록

입력

- 없음(프로그램이 쓴다)

출력

- 기록 폴더의 `dawon-fake-device-yyyyMMdd.jsonl`(UTC 날짜), 한 줄에 JSON 하나. 공통 필드 `ts`·`channel`·`direction`·`kind`, 채널별 `kind`와 항목 내용은 `R01-R9`. FOTA 본문은 기록하지 않고 기록 폴더 아래 `fota` 폴더에 파일로 둔다.

오류

- 없음

권한

- 기록 폴더를 읽는 사람(비밀 값은 `R01-R10`대로 가림)

코드

- `src/Biz.Bizadm.PowerManager.FakeDevice.App/Recording/FakeDeviceRecorder.cs`, `TopLevelJson.cs`

바뀔 것

- 없음

## C01-I4 콘솔 명령

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| `pub <토픽> <페이로드>` | 줄 | 아니오 | 그대로 발행 |
