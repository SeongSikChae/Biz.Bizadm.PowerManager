# D01_30 슬롯 A/B FOTA 코드 비교를 별도 작업으로 둔다

## 상황

tasks 검토 1회차 지적 2. plan 결정·위험이 "슬롯 B만 분석하되 슬롯 A와 비교해 FOTA 코드 동일 여부를 확인하고 다르면 적는다"고 했는데 tasks에 대응 작업이 없었다(검토 의견). 비교를 별도 작업으로 올릴지 기존 추적 작업에 접을지 정해야 했다.

- 정한 단계: tasks
- 관련: 옛 작업 스펙의 tasks.md T008(신설), 단계 2·의존 관계(`docs/specs/b540-fota-path/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_02`

## 결정

- A. 별도 작업: 단계 2에 "[P] 슬롯 A와 FOTA 형식 문자열·관련 함수 바이트 비교" 작업(T008)을 더한다.
- 옛 기록의 결정 칸: A(사용자 선택, 2026-11-20)

## 이유

- 별도 작업이면 T010 반영에서 빠지지 않고 체크포인트로 확인된다. B는 작업 수는 적지만 눈에 덜 띈다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
