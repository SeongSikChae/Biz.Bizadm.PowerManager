# D01_13 FOTA 요청의 User-Agent를 설정값으로 두고 기본값은 B540 덤프의 전체 문자열로 한다

## 상황

spec 검토 4회차 지적 2. C14의 "장치의 `User-Agent`"는 근거 문서가 `Mozilla/5.0 ... Chrome/30.0.1599.101`로 가운데를 줄여 적었고 저장소에 전체 문자열이 없어, 보낼 값과 테스트 기대값을 정할 수 없었다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C1, C14(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. 설정값, 기본은 덤프: C1 FOTA 설정에 `User-Agent`(기본: B540 펌웨어 덤프의 FOTA 요청 `User-Agent` 전체 문자열)를 더하고 C14는 설정값을 보낸다. 기본 문자열은 plan에서 덤프를 읽어 확정한다.

## 이유

- 다원이 `User-Agent`로 요청을 거르는지 모르므로 장치 값을 보낼 수 있어야 하고, 테스트는 설정값이 그대로 나가는지만 보면 된다. B는 다원이 `User-Agent`로 거르면 받기가 실패할 수 있다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
