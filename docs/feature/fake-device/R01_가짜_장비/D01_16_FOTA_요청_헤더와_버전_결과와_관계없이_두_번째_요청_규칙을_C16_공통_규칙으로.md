# D01_16 FOTA 요청 헤더와 "버전 결과와 관계없이 두 번째 요청" 규칙을 C16 공통 규칙으로 옮긴다

## 상황

`D01_14`(옛 D014) 보완. spec 검토 5회차 지적 1. "버전 요청의 결과와 관계없이 두 번째 요청도 보낸다"가 C14 자동 받기 문장에만 있어 C15 콘솔 두 요청 명령에서 버전 실패 때 동작이 정해지지 않았다. "같은 헤더로"는 두 요청 명령에만 붙어 단일 GET 명령의 헤더도 비어 있었다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C14, C15, C16(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. C16 공통 규칙으로: C14·C15에서 헤더와 결과 무관 규칙을 빼고, C16에 "모든 요청은 `Connection: keep-alive`와 C1 설정의 `User-Agent`를 보낸다"와 "두 요청을 보낼 때는 버전 요청의 결과와 관계없이 두 번째 요청도 보낸다"를 둔다.

## 이유

- 규칙이 한 곳에만 있어 다음에 다시 어긋나지 않는다. B는 같은 규칙이 두 곳에 생겨 한쪽만 고치면 다시 어긋난다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안
