# D01_34 장치의 버전 게이트는 흉내 내지 않는다

## 상황

실제 장치는 URL 안의 버전이 자기 펌웨어 버전보다 높을 때만 요청을 보낸다. 가짜 장비가 이 게이트를 흉내 낼지 정해야 했다. 비교할 부분 문자열의 정확한 경계는 펌웨어 분석에서 미확인이다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C1(버전 비교 없음)(`docs/specs/dawon-fake-device-fota-path/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_03`

## 결정

- A. 흉내 내지 않음: 버전 비교 없이 URL 후보를 찾으면 지금처럼 자동으로 받는다.
- 옛 기록의 결정 칸: A(사용자 선택, 2026-11-20)

## 이유

- 이 도구의 목적은 다원이 주는 것의 관찰·수집이다. 비교 경계가 미확인이라 흉내 내면 틀릴 수 있고, 펌웨어 버전 설정을 낮춰야 FOTA URL이 오므로 실제 상황에서도 결과는 거의 같다. B는 추정한 규칙을 요구로 박게 되고 관찰 기회를 줄여 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 장치처럼 비교: URL의 마지막 경로 조각과 `Device.FirmwareVersion`을 숫자 단위로 비교해 높을 때만 자동으로 받고, 아니면 건너뛴 것을 기록한다. | 위 「이유」에 함께 적힘 |
