# D01_24 실제 확인에 다원 앱의 켜기·끄기 조작을 plan에도 넣는다

## 상황

tasks 검토 1회차 지적 5. T029에 plan 검증 전략 C13 행에 없는 "다원 앱에서 켜기·끄기" 조작이 있어 plan과 tasks가 어긋났다. spec C13의 앱 조작 항목도 펌웨어 업데이트뿐이다. 다만 켜기·끄기는 다원이 장치에 보내는 `w` 같은 명령을 받아 보는 가장 직접적인 방법이고, spec "무엇을, 왜"의 목적(앱 조작 때의 `w`·`r`)과 맞는다.

- 정한 단계: tasks
- 관련: 옛 작업 스펙의 plan.md 검증 전략 C13(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. plan에 더함: plan C13 행을 "접속에 성공하면 사용자가 다원 앱에서 켜기·끄기와 펌웨어 업데이트를 조작한다. `FirmwareVersion: 1.01.30` 실행도 넣는다"로 고치고 T029는 그대로 둔다. plan 검토·확인을 다시 한다.

## 이유

- 서버 → 장치 명령 관찰이 이 작업의 주목적이다. B는 문서는 맞지만 앱 조작 때의 `w` 같은 명령을 관찰할 기회를 버린다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
