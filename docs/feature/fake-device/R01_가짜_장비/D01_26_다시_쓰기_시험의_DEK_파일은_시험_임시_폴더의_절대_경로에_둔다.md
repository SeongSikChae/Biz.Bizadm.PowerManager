# D01_26 다시 쓰기 시험의 DEK 파일은 시험 임시 폴더의 절대 경로에 둔다

## 상황

tasks 검토 3회차 지적 1. T009의 다시 쓰기 시험은 `ContentRootPath`를 비운 채 돌아 DEK 파일이 시험 출력 폴더에 생기는데, 시험 뒤 자격 증명만 지웠다. T006은 Salt가 비었는데 DEK 파일이 있으면 실패하므로(`DeviceConfig.App` `ConfigSecretProtector.cs` 37~44행과 같은 구조), 두 번째 시험 실행부터 2로 끝나 시험이 실패했다.

- 정한 단계: tasks
- 관련: 옛 작업 스펙의 tasks.md T009(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. DEK를 임시 폴더에: 시험 설정의 `OsKms.SecretsDekFilePath`를 시험 임시 폴더의 절대 경로로 두고(`Path.Combine`은 둘째 인자가 절대 경로면 그 값을 씀), 끝나면 임시 폴더와 시험용 자격 증명을 지운다.

## 이유

- 공유 폴더에 파일을 남기지 않아 다른 시험과 겹쳐 돌아도 안전하다. B는 공유 폴더에 잠시 파일이 생겨 다른 비밀 값 시험과 겹치면 서로 간섭할 수 있다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
