# D01_35 콘솔 `get` 명령은 주어진 URL 그대로 요청한다

## 상황

콘솔의 URL 하나만 GET하는 명령(R15 둘째, `get <URL>`)에도 접미사를 붙일지 정해야 했다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C4(`docs/specs/dawon-fake-device-fota-path/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_03`

## 결정

- A. 그대로 둠: `get <URL>`은 주어진 URL을 가공하지 않고 요청한다.
- 옛 기록의 결정 칸: A(사용자 선택, 2026-11-20)

## 이유

- 임의 경로(다른 슬롯, 다른 버전)를 시험하는 진단용이라 가공하지 않는 편이 쓸모 있고, 장치 형식은 `fota` 명령으로 받는다. B는 `fota` 명령과 겹치고 접미사 없는 경로를 시험할 방법이 사라져 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 장치 형식으로 바꿈: `get <URL>`도 `{URL}{접미사}`로 요청한다. | 위 「이유」에 함께 적힘 |

## 경위

- 2026-11-20 옛 작업 `docs/specs/dawon-fake-device-fota-path/decisions.md`(지움. `15dc357`에 있음) D004에서 옮겼다(2026-11-23).
