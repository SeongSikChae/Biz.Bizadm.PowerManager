# D01_14 FOTA 버전 요청 결과와 관계없이 두 번째 요청도 보내고, 실패는 그 요청만 멈춘다

## 상황

spec 검토 4회차 지적 3. C14·C15의 "두 요청을 차례로"와 C16의 "받기를 멈춘다"만으로는 버전 요청이 실패(404·시간 초과 등)했을 때 두 번째 요청을 보내는지 정해지지 않아 테스트 기대값이 갈렸다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C14, C16(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. 관계없이 둘 다: 버전 요청 결과와 관계없이 두 번째 요청도 보내고, C16의 멈춤은 그 요청 하나에만 적용한다.

## 이유

- 장치의 버전 비교 규칙이 미확인이라 흉내 내지 않고, 받을 수 있는 것을 최대한 받는 것이 목적에 맞다. B는 장치 흐름에 더 가깝지만 `/version`이 없는 서버에서 이미지를 받을 기회를 잃는다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
