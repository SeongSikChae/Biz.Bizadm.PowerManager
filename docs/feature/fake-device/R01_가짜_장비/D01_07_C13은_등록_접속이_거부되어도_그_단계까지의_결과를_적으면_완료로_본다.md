# D01_07 C13은 등록·접속이 거부되어도 그 단계까지의 결과를 적으면 완료로 본다

## 상황

spec 검토 1회차 지적 4. C13은 `rg`·`tisyn` 발행과 수신 확인을 적었지만 CONNACK 거부면 불가능해, 거부 결과만 적어도 완료인지 판정할 수 없었다. 1차 중계 시도에서 이미 409와 CONNACK 4가 나왔다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C13(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. 거부도 완료: 거부되면 그 단계까지의 결과(응답 상태, CONNACK 코드)를 적으면 완료로 보고, 발행·수신 항목은 접속에 성공했을 때만 적는다.

## 이유

- 다원 계정 상태는 이 작업이 통제할 수 없다. B는 목적에 더 맞지만 다원이 계속 거부하면 코드가 맞아도 작업이 끝나지 않는다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
