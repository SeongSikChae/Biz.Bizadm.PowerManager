# D01_05 verify 확인 서버 주소는 설정 오류로 검사하고, 치환표 밖 키는 판정 "계산 불가"로 기록하고 계속한다

## 상황

spec 검토 1회차 지적 2. device-register R3 계산식은 치환표 안 위치를 쓰므로 표 밖 문자가 있으면 계산할 수 없는데, C2는 키를 "비어 있지 않은 문자열"로만 보고 그때 처리가 없었다. C1의 `verify` 확인 서버 주소도 형식 검사 대상인지 정해지지 않았다. `DeviceVerify.Compute`는 표 밖 문자에 예외를 던진다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C1, C2(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. 계산 불가 기록: C1에 서버 주소가 치환표 문자로만 이뤄지지 않으면 설정 오류를 더하고, C2에 키가 표 밖 문자를 담으면 판정을 "계산 불가"로 기록·콘솔에 남기고 계속한다를 더한다.

## 이유

- 목적이 관찰이라 키가 예상 밖 형식이어도 그 키로 접속되는지 시험하는 편이 정보가 많다. B는 중계 모드와 기준이 같아지지만 그 시험 기회를 잃는다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 등록 실패로 종료: C1 설정 오류는 같고, C2 성공 조건을 치환표 문자열로 좁혀 아니면 MQTT 접속 없이 종료한다(dawon-relay R2와 같게). | 위 「이유」에 함께 적힘 |
