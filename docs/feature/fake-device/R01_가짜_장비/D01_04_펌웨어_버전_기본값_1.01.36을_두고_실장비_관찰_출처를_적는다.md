# D01_04 펌웨어 버전 기본값 1.01.36을 두고 실장비 관찰 출처를 적는다

## 상황

spec 검토 1회차 지적 1. C1 펌웨어 버전 기본값 `1.01.36`(C6 `rg`의 `/3/0/3`)이 근거 문서에 없다는 의견이다. `docs/reference/b540-mqtt-topic.md` 3절은 슬롯 A `1.01.30`, 슬롯 B `1.01.34`, 설정 섹터 `1.01.34`다. 값은 2026-11-19 서버 로그에서 B540 실장비가 보낸 `rg` 값이지만 spec에 출처가 없어 근거 문서와 모순처럼 읽혔다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 무엇을·왜(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. 출처 추가: 기본값 `1.01.36`을 두고 "무엇을, 왜"에 실장비 관찰 출처(정적 덤프는 `1.01.34`)를 더한다.

## 이유

- 실제 장비가 지금 다원에 보내는 값이라 다원이 받는 형식에 더 가깝다. B는 근거 문서와 맞지만 실장비보다 오래된 버전이라 다원 반응이 실장비와 달라질 여지가 생긴다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
