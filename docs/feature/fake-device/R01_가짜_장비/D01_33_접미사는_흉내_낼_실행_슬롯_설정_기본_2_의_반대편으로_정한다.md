# D01_33 접미사는 흉내 낼 실행 슬롯 설정(기본 2)의 반대편으로 정한다

## 상황

요청 경로 끝에 붙일 슬롯 접미사를 어떻게 정할지 정해야 했다. 실제 장치는 실행 중인 슬롯의 반대편 이미지를 받는다(user1 실행 중 → `_2`, user2 실행 중 → `_1`, GET 빌더가 실행 슬롯 판정 결과로 두 상수 가운데 고름). 덤프 장치(1.01.34)는 user2에서 돈다고 추정되어 실제로는 `_1`을 요청했을 것이다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C2(`docs/specs/dawon-fake-device-fota-path/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_03`

## 결정

- A. 실행 슬롯 설정, 기본 2: 설정 `Device.RunningSlot`(1|2, 기본 2)을 더하고, 실행 슬롯 2면 `_1`, 1이면 `_2`를 붙인다. 그 밖의 값은 설정 오류(종료 코드 2)다.
- 옛 기록의 결정 칸: A(사용자 선택, 2026-11-20)

## 이유

- A는 펌웨어의 실제 규칙(반대편 슬롯)을 그대로 따르고 기본값이 덤프 장치 상태(user2 실행)와 맞으며, 다른 슬롯 이미지도 설정만 바꾸면 받는다. B는 이미지 수집에는 편하지만 실제 장치는 요청을 하나만 보내 장치 흉내와 달라 고르지 않았다. C는 유연하지만 "반대편 슬롯"이라는 장치 규칙이 설정에 드러나지 않고 잘못된 값을 넣기 쉬워 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

| C. 접미사 직접 설정: 설정 `Fota.PathSuffix`(기본 `_1`)를 그대로 붙인다. | 위 「이유」에 함께 적힘 |
