# D01_27 설정 파일 다시 쓰기 시험은 실행기가 다 만들어진 뒤(T023)에 쓴다

## 상황

tasks 검토 4회차 지적 1. T009에 둔 다시 쓰기 시험은 "C4 연결 실패로 종료 코드 3"을 기대하는데, T009는 단계 1 작업이고 단계 1에는 실행기가 자리만 있다(T007). MQTT 접속은 단계 5(T020·T021)에서 생기므로 단계 1 체크포인트에서 이 시험이 통과할 수 없었다.

- 정한 단계: tasks
- 관련: 옛 작업 스펙의 tasks.md T009, T023, 단계 5 체크포인트, 의존 관계(`docs/specs/dawon-fake-device/`(지움. `15dc357`에 있음)), 짝 태스크 `T01_01`

## 결정

- A. T023 뒤로 옮김: 다시 쓰기 시험을 T009에서 빼서 T023 끝에 `Tests/ProgramTests.cs`로 두고, 단계 5 체크포인트에서 확인한다. 의존 관계에 이 순서를 적는다.

## 이유

- 한 번만 쓰고, 실행기가 다 있을 때 확인한다. B는 같은 시험을 두 번 고쳐야 하고 중간 기대값은 의미가 없다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
