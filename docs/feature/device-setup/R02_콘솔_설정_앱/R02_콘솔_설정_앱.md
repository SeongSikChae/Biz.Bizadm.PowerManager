# R02 콘솔 설정 앱

## 목적

사용자가 콘솔에서 설정 파일 하나로 B540 장치 설정 명령을 실행하려 한다. App은 YAML 설정의 `Commands`를 장치 설정 라이브러리(`R01`)로 순서대로 실행하고, 무선 어댑터·장치 AP·공유기 Wi-Fi는 콘솔 번호로 고르게 한다. 설정 파일의 비밀 값은 기동할 때 암호화해 둔다.

## 요구사항

| ID | 요구사항 | 상태 | 일감 |
| --- | --- | --- | --- |
| `R02-R1` | App은 실행 인수 `--config <yaml> --log <dir>`을 받고, 종료 코드를 정상 0, 인수 오류 1, 설정 오류 2, 실행 오류(명령 실패 포함) 3으로 돌려준다. 명령이 실패하면 PC Wi-Fi를 복구한 뒤 종료 코드 3으로 끝난다. | 반영 | |
| `R02-R2` | App은 YAML 설정(키는 속성 이름 그대로)에서 `ContentRootPath`·`OsKms`를 필수로, `Device`를 기본값(`ApPrefix` `DWD-`, `Host` `192.168.244.1`, `Port` 5000, `TimeoutSeconds` 10, `ApConnectTimeoutSeconds` 30)으로, `Commands`를 1개 이상 필수로 읽는다. `Commands`에 `ConnectAp`가 있으면 `WifiProfiles`(SSID 중복 금지)와 `Settings`를 필수로 본다. | 반영 | |
| `R02-R3` | App은 `Settings`에서 `ApiServerAddr`·`ApiServerPort`·`ServerAddr`·`ServerPort`·`UserId`를 필수(포트 1~65535)로, `SslSupport`(false)·`Company`(DAWONDNS)·`Model`(B540_W)·`Lati`("")·`Long`("")·`Topic`(dwd)·`Protocol`(V3)·`MqttKey`를 선택으로 읽는다. `Protocol`이 `V1`·`V2`·`V3`·`V4`(대소문자 구분)가 아니거나, `ConnectAp`가 있고 V1인데 `MqttKey`가 없으면 App은 PC Wi-Fi를 바꾸기 전에 설정 오류(종료 코드 2)로 끝난다. | 반영 | |
| `R02-R4` | 기동하면 App은 `WifiProfiles[].Pass`와 `Settings.MqttKey`를 OsKms(MCP rule `dotnet/kms-config-secrets.md`)로 암호화해 설정 파일에 다시 쓰고, 복호화한 값만 실행 옵션에 넣는다(YAML 모델의 암호문을 장치로 보내지 않는다). | 반영 | |
| `R02-R5` | App은 무선 어댑터·장치 AP·공유기 Wi-Fi(장치 `apscan`에 보인 등록 Wi-Fi, RSSI 순)를 콘솔 번호로 고르게 한다. 고르는 중 표준 입력이 닫히면 실행 오류로 끝난다. | 반영 | |

## 수용 기준

| ID | 대상 | 기준 | 최신 검증 |
| --- | --- | --- | --- |
| `R02-A1` | `R02-R1` | 인수가 빠지면 종료 코드 1, 설정이 틀리면 2, 명령이 실패하면 PC Wi-Fi가 접속 전 SSID로 돌아간 뒤 3, 모두 성공하면 0으로 끝난다. | |
| `R02-A2` | `R02-R2` | `Device`를 생략한 설정은 요구의 기본값으로 실행되고, `ContentRootPath`·`OsKms`가 없거나 `Commands`가 비었거나, `ConnectAp`가 있는데 `WifiProfiles`·`Settings`가 없거나 SSID가 중복되면 종료 코드 2로 끝난다. | |
| `R02-A3` | `R02-R3` | `Settings` 필수 항목이 없거나 포트가 범위 밖이면, `Protocol`이 `v3`처럼 대소문자가 다르거나 모르는 값이면, `ConnectAp`와 V1이 있는데 `MqttKey`가 없으면 PC Wi-Fi를 바꾸지 않고 종료 코드 2로 끝난다. 선택 항목을 생략하면 요구의 기본값이 쓰인다. | `V01_03` |
| `R02-A4` | `R02-R4` | 평문 `Pass`·`MqttKey`가 든 설정으로 기동하면 설정 파일의 두 값이 암호문으로 바뀌고, 장치로 보낸 설정 JSON에는 복호화한 원래 값이 들어간다. | `V01_03` |
| `R02-A5` | `R02-R5` | 콘솔에 번호 목록이 보이고 고른 번호의 어댑터·AP·Wi-Fi가 쓰이며, Wi-Fi 목록은 `apscan`에 보인 등록 Wi-Fi만 RSSI 높은 순으로 보인다. 고르는 중 표준 입력을 닫으면 종료 코드 3으로 끝난다. | `V01_01` |
