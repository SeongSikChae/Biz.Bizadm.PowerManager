# C02 계약

속한 스펙: `R02`

## 항목

| ID | 이름 | 종류 | 상태 |
| --- | --- | --- | --- |
| `C02-I1` | App 설정 파일(YAML) | 설정 파일 | 반영 |
| `C02-I2` | App 명령줄과 종료 코드 | 명령 | 반영 |

## 호환 규칙

- 바꿔도 되는 것: 새 선택 키(기본값이 지금 동작과 같을 때), 오류 문구
- 바꾸려면 결정 문서가 있어야 하는 것: 키 이름 변경·삭제, 필수 여부, 기본값, 종료 코드 값

## C02-I1 App 설정 파일(YAML)

입력

- 키는 속성 이름 그대로이며 필수·기본값·범위는 `R02-R2`·`R02-R3`에 있다. 모양은 코드의 `AppConfiguration`과 섹션 클래스를 따른다.

출력

- 기동하면 `WifiProfiles[].Pass`와 `Settings.MqttKey`의 평문이 `DEKENC:` 암호문으로 바뀌어 같은 파일에 다시 쓰인다(`R02-R4`).

오류

| 코드 | 나는 조건 |
| --- | --- |
| 종료 코드 2 | 필수 키 없음, 범위 밖, SSID 중복, `Protocol` 값 틀림, `ConnectAp`와 V1인데 `MqttKey` 없음 |

권한

- App을 실행하는 OS 계정(설정 파일 쓰기와 OsKms 금고 접근)

코드

- `src/Biz.Bizadm.PowerManager.DeviceConfig.App/AppConfiguration.cs`(`AppConfiguration`, `OsKmsSection`, `DeviceSection`, `WifiProfileSection`, `SettingsSection`)
- `src/Biz.Bizadm.PowerManager.DeviceConfig.App/Security/ConfigSecretProtector.cs`

바뀔 것

- 없음

## C02-I2 App 명령줄과 종료 코드

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| `--config` | 경로 | 예 | YAML 설정 파일 |
| `--log` | 경로 | 예 | 로그 폴더 |
| 표준 입력 | 줄 | 예 | 어댑터·장치 AP·Wi-Fi 번호 |

출력

- 종료 코드 0(정상), 1(인수 오류), 2(설정 오류), 3(실행 오류)

오류

| 코드 | 나는 조건 |
| --- | --- |
| 3 | 명령 실패(PC Wi-Fi 복구 뒤), 선택 중 표준 입력 닫힘 |

권한

- 콘솔 사용자

코드

- `src/Biz.Bizadm.PowerManager.DeviceConfig.App/Program.cs`, `ExitCode.cs`, `ConsoleDeviceConfigSelector.cs`

바뀔 것

- 없음
