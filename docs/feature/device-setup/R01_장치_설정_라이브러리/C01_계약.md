# C01 계약

속한 스펙: `R01`

## 항목

| ID | 이름 | 종류 | 상태 |
| --- | --- | --- | --- |
| `C01-E1` | 장치 설정 값(`DeviceSettings`) | 엔티티 | 반영 |
| `C01-I1` | 장치 SoftAP TCP 프로토콜 | 명령 | 반영 |
| `C01-I2` | 라이브러리 실행 진입점(`DeviceConfigRunner`, `IHostWifi`, `IDeviceConfigSelector`) | 모듈 사이 인터페이스 | 반영 |

## 호환 규칙

- 바꿔도 되는 것: 로그 문구, 내부 클래스 구성, 새 선택 필드(기본값이 지금 동작과 같을 때)
- 바꾸려면 결정 문서가 있어야 하는 것: 설정 JSON의 키 이름·순서·값 형식(장치 펌웨어가 읽음), 핸드셰이크·명령 문자열, `DeviceCommand` 이름(App 설정과 MCP 인자가 이름으로 씀), `DeviceProtocol` 값 이름

## C01-E1 장치 설정 값(`DeviceSettings`)

필드

- 코드의 `DeviceSettings` 속성을 따른다. 설정 JSON의 키 이름·순서는 `R01-R6`에 있다.

불변 조건

- `Protocol`이 `V1`이면 `MqttKey`(복호화된 값)가 비어 있지 않아야 장치에 보낸다(`R01-R10`).
- `ToString`과 로그는 `Pass`·`MqttKey`를 드러내지 않는다(`R01-R8`).
- 설정 JSON의 값은 모두 문자열이고 `ssl_support`는 `yes`/`no`다.

상태 전이

- 없음

코드

- `src/Biz.Bizadm.PowerManager.DeviceConfig/Protocol/DeviceProtocol.cs`(`DeviceProtocol`, `DeviceProtocols.TryParse`)

## C01-I1 장치 SoftAP TCP 프로토콜

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| 핸드셰이크 | 문자열 두 줄 | 예 | `[DUT<-PC] START\n`, `hello tcp SUCCESS_CONNECT\n`(연결마다) |
| 명령 | `DeviceCommand` | 예 | 명령마다 송신 문자열은 아래 명령 표 |
| 설정 JSON | JSON 한 줄 + `\n` | `ConnectAp`만 | `C01-E1`의 `ToJson` 결과 |

명령 표(모든 송신 줄은 `\n`으로 끝난다. 응답이 표의 형식과 다르면 실패)

| 명령 | 핸드셰이크 뒤 송신 | 응답 |
| --- | --- | --- |
| `ConnectAp` | `{"command":"apscan"}` → Wi-Fi 선택 → 설정 JSON → 흐름별 마무리(`R01-R5`). V3·V4는 `{"mac":"<mac>","command":"connectap"}` | `apscan` 목록, V3은 설정 JSON과 `connectap` 모두 `respone` `OK` |
| `ApScan` | `{"command":"apscan"}` | `{"SCAN_AP_LIST":{...}}`(중괄호 안이 키 없는 `"ssid:-51"` 나열이라 정식 JSON이 아님) |
| `Reboot` | `{"command":"reboot"}` | 응답이 오면 그대로, 시간 초과·연결 종료면 경고 후 성공 |
| `FactoryReset` | `{"command":"factoryreset"}` | `respone` `OK` |
| `ScanAp` | `[DUT<-PC] SCAN_AP` | `{"SCAN_AP_LIST":{...}}` |
| `OnCmd` | `[DUT<-PC] ON_CMD` | `[DUT->PC] ON_CMD_OK#` |
| `OffCmd` | `[DUT<-PC] OFF_CMD` | `[DUT->PC] OFF_CMD_OK#` |
| `Measurement` | `[DUT<-PC] MEASUREMENT` | `[DUT->PC] MEASUREMENT_W:<숫자>#` |
| `OverLoad` | `[DUT<-PC] OVERLOAD` | `#` 프레임이면 성공(실장비 예: `[DUT->PC] OVERLOAD_A:0.160#`) |
| `TestFactoryReset` | `[DUT<-PC] FACTORY_RESET` | `Reboot`와 같음 |

출력

- `[DUT->PC] START_OK:<mac>#`의 MAC, 명령별 응답 프레임(`#` 프레임 또는 JSON), `apscan`의 `SCAN_AP_LIST`

오류

| 코드 | 나는 조건 |
| --- | --- |
| `TimeoutException` | 응답을 기다리는 단계에서 `Device.TimeoutSeconds` 안에 응답 없음 |
| `IOException` | 응답 전에 장치가 연결을 닫음 |
| `DeviceProtocolException` | 응답 형식이 다르거나 `respone`이 `OK`가 아님, 첫 프레임이 `START_OK`가 아님 |
| `InvalidOperationException` | V1인데 `MqttKey` 없음 |

권한

- 장치 SoftAP에 접속한 PC(인증 없음)

코드

- `src/Biz.Bizadm.PowerManager.DeviceConfig/Protocol/DeviceMessages.cs`, `DeviceResponseParser.cs`
- `src/Biz.Bizadm.PowerManager.DeviceConfig/Transport/DeviceClient.cs`, `DeviceConnection.cs`, `DeviceFrameReader.cs`, `DeviceCommand.cs`

## C01-I2 라이브러리 실행 진입점

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| 옵션 | `DeviceConfigOptions` | 예 | `Device`(AP 접두·주소·포트·대기 시간), `Commands`, `WifiProfiles`, `Settings` |
| PC Wi-Fi | `IHostWifi` | 예 | OS별 런타임(`HostWifiLoader`)이 만든다. 미구현 OS는 `NotImplementedException` |
| 선택기 | `IDeviceConfigSelector` | 예 | 어댑터·장치 AP·공유기 Wi-Fi 고르기(App은 콘솔, MCP는 인자) |

출력

- 명령마다 `DeviceCommandResult`(명령, 응답 문자열) 통보

오류

| 코드 | 나는 조건 |
| --- | --- |
| 예외 전파 | PC Wi-Fi 실패(미구현 OS 빼고), 명령 실패, 취소. 장치 AP 접속을 시도했으면 전파 전에 복구 |
