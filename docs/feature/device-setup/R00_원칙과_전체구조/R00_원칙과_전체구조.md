# R00 원칙과 전체구조

## 목적

사용자가 PC에서 B540(DAWONDNS `B540_W`, ESP8266) 장치의 SoftAP에 접속해 장치를 설정하는 도구 묶음이다. 장치 AP 접속 → 명령 실행 → PC Wi-Fi 복구를 하는 라이브러리 하나를 콘솔 App과 MCP 서버가 함께 쓴다. 사용자는 장치를 공유기와 PowerManager 서버에 붙이거나(`ConnectAp`) 장치 명령(재부팅, 측정 등)을 실행한다.

## 스펙 목록

| 번호 | 제목 | 한 줄 요약 |
| --- | --- | --- |
| `R01` | 장치 설정 라이브러리 | 장치 AP 접속, SoftAP TCP 명령·`ConnectAp` 흐름 V1~V4, PC Wi-Fi 복구 |
| `R02` | 콘솔 설정 앱 | YAML 설정과 콘솔 번호 선택으로 라이브러리를 실행하는 App |
| `R03` | MCP 설정 서버 | 라이브러리를 MCP Streamable HTTP tool로 제공하는 서버 |
