# R03 서버 설정 보안값

## 목적

운영자가 서버(`Server.Spa`) 설정 파일에 TLS 인증서 비밀번호를 평문으로 두지 않으려 한다. 서버는 보안값을 Biz.Bizadm.KMS로 보호한다. 보안값은 로컬 DEK(`OsKms.SecretsDekFilePath`)로 암호화하고, DEK를 보호하는 KEK는 OS 자격 증명 저장소에 둔 패스워드와 `OsKms.Salt`로 만든다. 운영자는 Linux에서 자격 증명 저장소를 설정으로 고를 수 있다.

## 지금 동작

- KMS 처리는 설정 검사 뒤 `KmsSecretProtector.Protect`가 하며, 실패하면 설정 오류(종료 코드 2)로 끝난다(`Program.RunAsync`).
- gpg 저장소를 쓸 때 직접 실행과 서비스 실행이 같은 키를 쓰려면 같은 OS 계정이고 저장소 위치(환경 변수 `PASSWORD_STORE_DIR`, git 설정 `credential.gpgPassStorePath`, 홈의 `.password-store` 순)가 같아야 한다. gpg 키는 암호 입력 없이 쓸 수 있어야 한다(암호가 걸린 키의 동작은 미확인).
- 첫 기동 뒤 `CredentialStore`를 바꾸면 KEK 패스워드를 다른 저장소에서 찾아 기동이 실패한다.
