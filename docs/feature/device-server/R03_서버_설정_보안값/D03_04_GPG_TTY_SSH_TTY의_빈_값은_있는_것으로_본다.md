# D03_04 GPG_TTY·SSH_TTY의 빈 값은 있는 것으로 본다

## 상황

spec 검토 3회차 전체 점검 지적 2. `D03_01`(옛 D001)과 「무엇을, 왜」는 두 변수가 모두 없을 때만 서버가 채운다고 하는데 C3은 "없거나 빈 값"까지 채운다. `ValidateGpgPass`는 변수가 있으면 값이 비어도 있는 것으로 본다(`ContainsKey`). 어느 쪽으로 맞출 것인가.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C3(`docs/specs/credential-store/`(지움. `15dc357`에 있음)), 짝 태스크 `T03_01`

## 결정

- A. 빈 값 조건 삭제: C3을 "모두 없으면 넣는다. 하나라도 있으면(빈 값 포함) 바꾸지 않는다"로 고친다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 빈 값도 채움: C3을 두고 「무엇을, 왜」를 넓히며 D001을 대체하는 결정을 만든다. | 사용자가 말하지 않음 |
| C. 고치지 않음: 두 문장을 그대로 둔다. | 사용자가 말하지 않음 |
