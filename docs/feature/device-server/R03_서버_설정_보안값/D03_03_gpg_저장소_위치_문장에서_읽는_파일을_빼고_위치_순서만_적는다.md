# D03_03 gpg 저장소 위치 문장에서 읽는 파일을 빼고 위치 순서만 적는다

## 상황

spec 검토 3회차 지적 1. 검토 의견은 "git 설정 `credential.gpgPassStorePath`(홈의 `.gitconfig`)"의 괄호가 적은 출처 `ValidateGpgPass`에 없고, 실제로는 `NoGit`이 파일을 정하며 `Config.Build`가 `.gitconfig` 외의 파일도 읽는다는 것이다. 적힌 출처로 확인할 수 없는 설명이 남는다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「하지 않는 것」(`docs/specs/credential-store/`(지움. `15dc357`에 있음)), 짝 태스크 `T03_01`

## 결정

- A. 괄호 삭제: "(홈의 `.gitconfig`)"를 뺀다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 출처 추가: "홈의 `.gitconfig` 등, `CommandContextAdapter.NoGit`"으로 쓴다. | 사용자가 말하지 않음 |
| C. 고치지 않음: 괄호를 그대로 둔다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-23 옛 작업 `docs/specs/credential-store/decisions.md`(지움. `15dc357`에 있음) D003에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T03_01`의 「고칠 파일」을 본다.
