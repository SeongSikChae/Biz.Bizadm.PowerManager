# D03_02 C7의 전제를 적고 직접 실행은 SSH 로그인 터미널로 정한다

## 상황

spec 검토 1회차 지적 2. 검토 의견은 C7·「무엇을, 왜」·「하지 않는 것」에 두 실행이 같은 OS 계정이어야 한다는 조건과 gpg 키를 암호 입력 없이 쓸 수 있어야 한다는 조건이 없고, "터미널 직접 실행"이 SSH 로그인인지 `sudo -u` 같은 실행인지 정해지지 않았다는 것이다. `ValidateGpgPass`는 저장소를 `PASSWORD_STORE_DIR` 또는 홈의 `.password-store`로 정하므로, 계정이 다르면 C7이 실패해도 결함인지 전제 위반인지 가릴 수 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「하지 않는 것」, C7(`docs/specs/credential-store/`(지움. `15dc357`에 있음)), 짝 태스크 `T03_01`

## 결정

- A. 전제·SSH 명시: 「하지 않는 것」에 같은 OS 계정과 암호 없는 gpg 키 전제(암호 걸린 키는 미확인)를 적고, C7 (가)를 SSH 로그인 터미널 직접 실행, (나)를 `SSH_TTY`가 없는 서비스 실행으로 정한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. A + 추가 실행 확인: A에 더해 `SSH_TTY`와 `GPG_TTY`를 뺀 직접 실행을 세 번째로 확인한다. | 사용자가 말하지 않음 |
| C. 고치지 않음: 전제와 실행 종류를 적지 않는다. | 사용자가 말하지 않음 |
