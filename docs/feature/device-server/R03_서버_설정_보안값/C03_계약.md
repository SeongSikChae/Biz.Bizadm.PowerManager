## C03-I1 KMS 설정과 보호된 TLS 비밀번호

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| `OsKms.CredentialService` | 절대 URI | 예 | 자격 증명 저장소의 서비스 이름 |
| `OsKms.CredentialAccount` | 문자열 | 예 | 자격 증명 계정 |
| `OsKms.Salt` | 문자열 | 아니오 | 비어 있으면 첫 기동 때 만들어 설정 파일에 기록 |
| `OsKms.Iterations` | 정수 | 예 | KEK 유도 반복 수 |
| `OsKms.SecretsDekFilePath` | 경로 | 예 | 로컬 DEK 파일 |
| `OsKms.CredentialStore` | 문자열 | 아니오 | `gpg`·`secretservice`(대소문자·공백 그대로). 없거나 공백이면 KMS 패키지 기본 |
| `Tls.ServerCertificatePassword` | 문자열 | `UseTls`가 참일 때 | 평문이면 기동 때 `DEKENC:` 암호문으로 다시 쓰임 |

출력

- 설정 파일 다시 쓰기(`Salt`, 암호문), 서버 프로세스 환경 변수 `GCM_CREDENTIAL_STORE`·`GPG_TTY`(`R03-R6`·`R03-R7`)

오류

| 코드 | 나는 조건 |
| --- | --- |
| 종료 코드 2 | `CredentialService`가 절대 URI가 아님, `CredentialStore`가 허용 값 밖, KMS 처리 실패(첫 기동 뒤 저장소를 바꿔 KEK 패스워드를 찾지 못함 포함) |

권한

- 서버를 실행하는 OS 계정(직접 실행과 서비스가 같은 키를 쓰려면 같은 계정·같은 저장소 위치)

코드
