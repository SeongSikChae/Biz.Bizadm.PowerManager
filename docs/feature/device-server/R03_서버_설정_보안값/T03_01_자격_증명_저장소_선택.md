### 단계 4: 확인
- 솔루션 빌드·전체 테스트, 빌드한 서버를 `CredentialStore: plaintext`로 실행, 화면 없는 Linux 서버에서 직접 실행과 서비스 실행을 번갈아 기동.

확인: 빌드 경고 0·테스트 통과, `plaintext`는 종료 코드 2와 허용 값 문구, Linux에서 직접 → 서비스 → 직접 실행이 같은 gpg 키로 기동.

## 위험

- `Validate`를 거치지 않고 `Protect`를 부르면 허용하지 않는 값이 환경 변수에 들어갈 수 있다(서버는 검사 뒤에 부름).
- 환경 변수는 서버 프로세스 전체에 영향을 준다(서버는 KMS 밖에서 자격 증명 저장소를 쓰지 않음).
- Windows에서 `gpg`는 패키지가 POSIX 전용 오류로 실패한다.
- 암호가 걸린 gpg 키의 동작은 미확인이다.
- 첫 기동 뒤 `CredentialStore`를 바꾸면 KEK 패스워드를 찾지 못한다(저장소 이전은 다루지 않음).
