# C01 계약

속한 스펙: `R01`

## 항목

| ID | 이름 | 종류 | 상태 |
| --- | --- | --- | --- |
| `C01-E1` | 장치 등록(`DeviceRegistration`) | 엔티티 | 반영 |
| `C01-I1` | 장치 등록 `POST /api/v1/devices/register/create` | API | 반영 |
| `C01-I2` | 접속 조회 `GET /api/v1/device/connect/{deviceKey}` | API | 반영 |
| `C01-I3` | 장비명 저장 `PUT /api/admin/devices/{mac}/name` | API | 반영 |
| `C01-I4` | 등록 관련 서버 설정(`DeviceMqttServerAddr`, `DatabasePath`) | 설정 파일 | 반영 |

## 호환 규칙

- 바꿔도 되는 것: ProblemDetails의 `title`·`detail` 문구, 새 DB 열(기본값이 있을 때, 마이그레이션 포함)
- 바꾸려면 결정 문서가 있어야 하는 것: 장치 API의 경로·본문 키·키 순서·상태 코드(장치 펌웨어가 읽음), `verify` 계산식과 치환표, `mqtt_key` 형식, DB 열 삭제·형 변경, 장비명 규칙

## C01-E1 장치 등록(`DeviceRegistration`)

필드

- 코드의 `DeviceRegistration`과 `PowerManagerDbContext` 모델(테이블 `Devices`, PK `Mac`, 길이 제한)을 따른다.

불변 조건

- `Mac`은 소문자 12자리 16진수이고 한 행만 있다.
- `MqttKey`는 처음 등록 때 정해지고 다시 등록해도 바뀌지 않는다(`R01-R6`).
- `UserId`·`ModelId`·`Company`는 빈 값이 아닌 요청 값으로만 바뀐다. `Name`은 장치 요청으로 바뀌지 않고 `C01-I3`로만 바뀐다.
- `RegisteredAt`은 바뀌지 않고 `LastRequestedAt`은 등록 요청마다 바뀐다(장비명 변경으로는 바뀌지 않음).

상태 전이

- 없음(행은 지우지 않는다)

코드

- `src/Biz.Bizadm.PowerManager.Server.Spa/Data/DeviceRegistration.cs`, `PowerManagerDbContext.cs`, `Migrations/`
- `src/Biz.Bizadm.PowerManager.Server.Spa/Devices/DeviceRegistrationService.cs`

바뀔 것

- 없음

## C01-I1 장치 등록

입력

- 본문은 `DeviceRegisterRequest`(`account.user_id`, `device.mac`·`model_id`·`company` 등). `device.mac`만 검사한다(`R01-R4`).

출력

- 200 `application/json` `{"verify":"<44자>","mqtt_key":"<16자>"}`(키 둘, 이 순서). `verify`는 `C01-I4`의 서버 주소로 계산한다.

오류

| 코드 | 나는 조건 |
| --- | --- |
| 400 | `device.mac`이 12자리 16진수가 아님(없거나 빈 값 포함). 저장하지 않음 |

권한

- 장치 포트·관리 포트 모두(인증 없음)

코드

- `src/Biz.Bizadm.PowerManager.Server.Spa/Devices/DevicesController.cs`(`Register`)
- `src/Biz.Bizadm.PowerManager.Core/Devices/DeviceRegisterRequest.cs`, `DeviceRegisterResponse.cs`, `DeviceVerify.cs`, `MqttKeyGenerator.cs`

바뀔 것

- 없음

## C01-I3 장비명 저장

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| `mac` | 경로 문자열 | 예 | 12자리 16진수 |
| `name` | 문자열 | 예 | 앞뒤 공백(`char.IsWhiteSpace`)을 없앤 뒤 30 UTF-16 코드 단위 이하, 제어 문자·U+2028·U+2029 없음. 빈 값이면 장비명 삭제 |

출력

- 204. 값이 바뀌었으면 상태 스트림(`admin/C04-I2`)에 그 장비의 `device` 이벤트

오류

| 코드 | 나는 조건 |
| --- | --- |
| 400 | mac 형식(먼저), 장비명 규칙 위반(등록 확인 뒤) |
| 404 | 등록되지 않은 mac, 장치 포트로 부름 |

권한

- 관리 포트만(`admin/R01-R6`)

코드

- `src/Biz.Bizadm.PowerManager.Server.Spa/Devices/AdminDevicesController.cs`, `DeviceName.cs`, `DeviceNameRequest.cs`, `DeviceRegistrationService.cs`(`RenameAsync`)

바뀔 것
