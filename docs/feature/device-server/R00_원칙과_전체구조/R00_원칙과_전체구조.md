# R00 원칙과 전체구조

## 목적

B540·M130-W 장치가 다원 서버 대신 붙는 PowerManager 서버(`Server.Spa`)의 장치 쪽 기능이다. 장치는 REST로 등록해 MQTT 키를 받고, 내장 MQTT 브로커에 그 키로 접속해 상태를 보고하고 제어 메시지를 받는다. 서버 설정의 보안값은 KMS로 보호한다. 관리 화면과 관리 API는 `admin` 영역이 맡는다.

## 스펙 목록

| 번호 | 제목 | 한 줄 요약 |
| --- | --- | --- |
| `R01` | 장치 등록과 접속 조회 | 등록 API의 `mqtt_key` 발급·`verify` 계산·SQLite 저장, 접속 조회, 장비명 저장 API |
| `R02` | MQTT 브로커 | 내장 브로커의 엔드포인트·인증, 토픽 해석과 분배, `tisyn` 응답, 명령 발행, 관찰 로그 |
| `R03` | 서버 설정 보안값 | TLS 인증서 비밀번호의 KMS 보호와 자격 증명 저장소 선택 |
