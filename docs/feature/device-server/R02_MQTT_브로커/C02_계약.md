# C02 계약

속한 스펙: `R02`

## 항목

| ID | 이름 | 종류 | 상태 |
| --- | --- | --- | --- |
| `C02-I1` | 장치 → 서버 토픽과 메시지 | 이벤트 | 반영 |
| `C02-I2` | 서버 → 장치 토픽과 메시지 | 이벤트 | 반영 |
| `C02-I3` | `IDeviceMessageHandler` | 모듈 사이 인터페이스 | 반영 |
| `C02-I4` | `IDeviceCommandPublisher` | 모듈 사이 인터페이스 | 반영 |
| `C02-I5` | 브로커 설정(`MqttPort`, `MqttsPort`, `Tls`) | 설정 파일 | 반영 |

## 호환 규칙

- 바꿔도 되는 것: 로그 문구(관찰용, 다른 프로그램이 읽지 않음), 핸들러 구현, 새 오퍼레이션 분배
- 바꾸려면 결정 문서가 있어야 하는 것: 토픽 형식, 메시지 형식(장치 펌웨어가 읽음), 접속 인증 규칙, 엔드포인트 TLS 버전, 인터페이스 메서드 시그니처, 설정 키 이름

## C02-I1 장치 → 서버 토픽과 메시지

입력

- 토픽 `{prefix}.v1/{deviceKey}/iot-server/{접미}`(빈 토큰 무시, 끝이 `lwt`면 LWT). 페이로드 `{"sid":…,"msg":{"o":"<op>","e":[{"n":"<경로>","sv":"<값>",…}]}}`(`MqttEnvelope`)

출력

- `C02-I3`로 분배, 장비 상태 저장소로 전달(`R02-R15`)

오류

| 코드 | 나는 조건 |
| --- | --- |
| Warning 로그, 분배 안 함 | JSON 오류, `msg.o`·`msg.e` 없음 |
| Warning 로그 | 다섯 오퍼레이션 밖의 `msg.o` |
| Information 로그, 그대로 전달 | 해석할 수 없는 토픽 |

권한

- `R02-R9` 판정이 `Match`인 클라이언트(등록 장치가 등록 키로 접속)

코드

- `src/Biz.Bizadm.PowerManager.Core/Mqtt/DeviceTopic.cs`, `DeviceTopicKind.cs`, `MqttEnvelope.cs`, `MqttOperation.cs`
- `src/Biz.Bizadm.PowerManager.Server.Spa/Mqtt/MqttBrokerHostedService.cs`

바뀔 것

- 없음

## C02-I2 서버 → 장치 토픽과 메시지

입력

- 토픽 `{prefix}.v1/iot-server/{deviceKey}`(retain 없음). 페이로드는 `C02-I1`과 같은 모양. `sid`는 `tisyn` 응답이면 요청 `sid`(없으면 `"0"`), 명령이면 서버 실행마다 100부터 1씩 늘린 10진 문자열

출력

- 구독한 장비 클라이언트의 전송 큐

오류

| 코드 | 나는 조건 |
| --- | --- |
| Warning 로그 | 맞는 구독이 없음(`R02-R13`) |

권한

- 서버 주입(보낸 ClientId `power-manager`) 또는 등록 장치 클라이언트

코드

- `src/Biz.Bizadm.PowerManager.Core/Mqtt/DeviceTopic.cs`(`ToDevice`, `IsToDevice`)
- `src/Biz.Bizadm.PowerManager.Server.Spa/Mqtt/LoggingDeviceMessageHandler.cs`, `MqttDeviceCommandPublisher.cs`

바뀔 것

- 없음

## C02-I4 `IDeviceCommandPublisher`

입력

- `PublishAsync(DeviceCommandTarget(Mac, Prefix, DeviceKey), string operation, IReadOnlyList<MqttElement>, CancellationToken)`

출력

- `DevicePublishResult(Enqueued, Topic, Sid)`. `Enqueued`는 ClientId `DAWONDNS-{mac}`의 전송 큐에 들어갔다는 브로커 이벤트를 3초 안에 받았는지다. 장치가 받았거나 처리했다는 뜻이 아니다.

오류

| 코드 | 나는 조건 |
| --- | --- |
| `Enqueued = false` + Warning | 3초 안에 이벤트 없음(구독자 없음 포함) |
| `Enqueued = false` + Error | 브로커 없음, 예외 |

권한

- 서버 안(`admin` 영역의 제어 API, 릴레이 읽기)

코드

- `src/Biz.Bizadm.PowerManager.Core/Mqtt/IDeviceCommandPublisher.cs`, `DeviceCommandTarget.cs`, `DevicePublishResult.cs`
- `src/Biz.Bizadm.PowerManager.Server.Spa/Mqtt/MqttDeviceCommandPublisher.cs`, `DownlinkDeliveryTracker.cs`

바뀔 것

- 없음

## C02-I5 브로커 설정

입력

| 이름 | 형 | 필수 | 뜻 |
| --- | --- | --- | --- |
| `MqttPort` | 포트 | 예 | 비TLS 엔드포인트 |
| `MqttsPort` | 포트 | `Tls.UseTls`가 참일 때 | TLS 1.2·1.3 엔드포인트 |
| `Tls.ServerCertificate`·`ServerCertificatePassword` | 문자열 | `UseTls`가 참일 때 | 서버 인증서(비밀번호는 `R03`가 보호) |
| `Tls.IncludeCipherSuites` | 문자열 | 아니오 | HTTPS와 같은 규칙으로 MQTTS에도 적용(`R02-R18`) |
| `Tls.CertificateChain` | 문자열 | 아니오 | HTTPS에만 적용, MQTTS에는 적용하지 않음 |

출력

- 패킷 분할을 끈 두 엔드포인트(`R02-R14`)

오류

| 코드 | 나는 조건 |
| --- | --- |
| 종료 코드 2 | 설정 검사 실패 |

권한

- 서버 운영자

코드

- `src/Biz.Bizadm.PowerManager.Server.Spa/AppConfiguration.cs`, `src/Biz.Bizadm.PowerManager.Server.Core/TlsConfiguration.cs`, `ServerKestrelExtensions.cs`(`ResolveCipherSuites`)
- `src/Biz.Bizadm.PowerManager.Server.Spa/Mqtt/MqttBrokerHostedService.cs`(`BuildServerOptions`)
