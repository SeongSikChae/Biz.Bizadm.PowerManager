# D02_17 예외 때 판정은 `Unknown`으로 두고 C3에서 예외를 뺀다

## 상황

spec 검토 3회차 지적 1. 검토 의견: C3은 "판정이 `Unknown`이면 CONNACK 4", C6은 "C4의 예외 때 판정은 `Unknown`", C4는 "예외면 CONNACK 3"이라 예외가 난 접속에 반환 코드 3과 4가 함께 정해진다. 판정 값만으로 반환 코드를 고르게 구현하면 `D02_15`(옛 D002)가 정한 CONNACK 3 대신 4가 나갈 수 있고, 기준 spec으로 옮길 때도 모순이 넘어가므로 문제다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C3(`docs/specs/mqtt-connect-auth/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_09`

## 결정

- A. C3에 예외 단서: C3 조건에 "C4의 예외 때는 빼고"를 더한다. 로그 판정 값(`Unknown`)은 그대로 둔다.

## 이유

- A는 C3 한 줄만 바꾸고 R9 로그 형식을 그대로 둔다. B는 로그로 예외와 미등록을 가를 수 있지만, 예외 때는 Error 로그가 따로 남아 얻는 것이 작고 로그 형식·테스트·기준 spec 고칠 곳이 늘어 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
