# D02_21 서버 인증서 체인도 MQTTS에 적용한다

## 상황

`Tls.CertificateChain`을 MQTTS에도 적용할지. 질문할 때 "MQTTS는 서버 인증서만 보낸다"고 안내했다(이 안내는 틀렸음, `D02_22`(옛 D003)).

- 정한 단계: spec
- 관련: 옛 작업 스펙의 D003으로 대체(`docs/specs/mqtts-tls-policy/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_10`

## 결정

- B. 함께 적용: MQTTS도 HTTPS와 같은 체인을 보낸다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| A. 이번엔 빼기: 이번 작업은 TLS 버전과 암호 목록만 다룬다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-23 옛 작업 `docs/specs/mqtts-tls-policy/decisions.md`(지움. `15dc357`에 있음) D002에서 옮겼다(2026-11-23).
- 뒤에 `D02_22`(옛 D003)이 이 결정을 대신했다.

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T02_10`의 「고칠 파일」을 본다.
