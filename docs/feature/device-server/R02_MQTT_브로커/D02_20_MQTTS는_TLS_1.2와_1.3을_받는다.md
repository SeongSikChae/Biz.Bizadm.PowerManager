# D02_20 MQTTS는 TLS 1.2와 1.3을 받는다

## 상황

MQTTS 엔드포인트의 TLS 버전을 어떻게 할지. 지금은 TLS 1.2 고정이고 HTTPS(Kestrel)는 TLS 1.2·1.3을 받는다. 장치(B540·M130-W)는 TLS 1.2만 제시한다(2026-11-23 ClientHello 캡처).

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C1(`docs/specs/mqtts-tls-policy/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_10`

## 결정

- A. 1.2·1.3: HTTPS와 같게 TLS 1.2와 1.3을 받는다. 1.0·1.1은 계속 막고, 암호 목록의 TLS 1.3 항목도 MQTTS에서 쓰인다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. OS에 맡김: 버전을 고정하지 않고 MQTTnet 기본값(`SslProtocols.None`)으로 OS가 고르게 한다. | 사용자가 말하지 않음 |
| C. 1.2 유지: 버전은 TLS 1.2 고정으로 두고 암호 목록만 적용한다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-23 옛 작업 `docs/specs/mqtts-tls-policy/decisions.md`(지움. `15dc357`에 있음) D001에서 옮겼다(2026-11-23).
