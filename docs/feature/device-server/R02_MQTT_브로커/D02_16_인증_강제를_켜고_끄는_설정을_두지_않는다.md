# D02_16 인증 강제를 켜고 끄는 설정을 두지 않는다

## 상황

인증 강제를 설정 항목으로 켜고 끌 수 있게 할지(끄면 지금처럼 판정 로그만 남기고 모두 받음).

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C5(`docs/specs/mqtt-connect-auth/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_09`

## 결정

- B. 늘 강제: 설정을 더하지 않고 늘 인증을 강제한다. 끄려면 코드를 바꿔 다시 배포해야 한다.

## 이유

- 사용자가 B를 골랐다. B는 설정 항목·검증·테스트가 늘지 않아 가장 단순하다. A는 되돌리기는 쉽지만 설정 항목과 그 검증·테스트가 늘어 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| A. 설정으로 켬/끔: `AppConfiguration`에 불(bool) 설정 하나를 더하고 기본값을 켬(강제)으로 둔다. 등록하지 않은 장치를 붙여야 할 때 코드 배포 없이 끌 수 있다. | 위 「이유」에 함께 적힘 |
