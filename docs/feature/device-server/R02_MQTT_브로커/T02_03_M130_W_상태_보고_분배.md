## 할 일

### 단계 1: 분배 코드
- `n`을 `NotifyAsync`로 원래 값 그대로 넘긴다(`R02-R4`).

### 단계 2: 테스트
- `n`과 `notify`가 둘 다 `NotifyAsync`로 가고, `n`에는 알 수 없는 오퍼레이션 경고가 남지 않는다.

확인: `dotnet test` 전체 실패 0.
