## 위험

- MQTTnet 5.2는 네 이벤트를 예외를 잡지 않고 부른다. 전달 이벤트의 예외는 분배 루프를 멈추므로 처리기마다 예외를 막는다.
- 장치 → 서버 메시지마다 구독자 없음 이벤트가 와서 이 처리기가 모든 상향 경로에 있다(`IsToDevice`로 걸러 로그는 없음).
- 주입 메시지의 보낸 ClientId와 구독자 없음 이벤트 발생은 문서에 없어 테스트로 확인했다.
