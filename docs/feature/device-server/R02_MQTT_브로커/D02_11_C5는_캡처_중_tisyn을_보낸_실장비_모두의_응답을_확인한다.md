# D02_11 C5는 캡처 중 tisyn을 보낸 실장비 모두의 응답을 확인한다

## 상황

spec 검토 2회차 지적 1. C5가 "실장비의 `tisyn`에 대한 응답"이라고만 해 몇 대를 확인해야 충족인지 정해져 있지 않다. B540까지 요구하는 것으로 읽으면 B540이 캡처 시간 안에 `tisyn`을 보내지 않을 때(2026-11-21 캡처에서 B540으로 추정되는 연결은 PING만 주고받음) C5를 끝낼 수 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C5(`docs/specs/mqtt-no-fragmentation/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_07`

## 결정

- A. tisyn 보낸 장비 모두: "캡처하는 동안 `tisyn`을 보낸 실장비(적어도 한 대)마다 그 응답이 모두 TLS 레코드 하나로 나가면 충족"으로 고친다.

## 이유

- A는 범위가 분명하고, 특정 장비가 `tisyn`을 보내지 않아도 끝낼 수 있으며, 캡처에 잡힌 장비는 빠짐없이 확인한다. B는 송신 코드가 같아 결과는 거의 같지만 잡힌 다른 장비의 응답을 보지 않아도 되어 확인이 약하다. 고치지 않으면 완료 판정이 읽는 사람마다 달라진다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
