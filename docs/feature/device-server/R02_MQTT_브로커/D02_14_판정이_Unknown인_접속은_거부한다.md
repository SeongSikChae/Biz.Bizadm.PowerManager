# D02_14 판정이 `Unknown`인 접속은 거부한다

## 상황

mqtt-broker R9의 판정 `Unknown`(ClientId가 `DAWONDNS-{12자리 16진수}` 형식이 아니거나, 그 mac이 `device-register`에 등록돼 있지 않음)인 접속을 받을지 거부할지. V1 설정 도구로 `mqtt_key`를 장치에 직접 넣고 서버 등록(`POST /api/v1/devices/register/create`)을 거치지 않은 장치(예: M130-W)도 여기에 들어갈 수 있다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C3(`docs/specs/mqtt-connect-auth/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_09`

## 결정

- A. 거부: 등록된 mac의 장치가 등록 `mqtt_key`로 접속할 때(`Match`)만 받는다. 등록하지 않은 장치와 형식이 다른 클라이언트는 접속하지 못한다.

## 이유

- A는 등록·키 없는 접속을 막는다는 인증 강제의 목적을 그대로 채운다. B는 등록되지 않은 mac이나 형식이 다른 ClientId로는 누구나 접속할 수 있어, 인증 효과가 등록된 mac을 사칭하는 경우로만 줄어들어 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 허용: 등록된 mac인데 비밀번호가 틀린 경우(`Mismatch`)만 거부하고, `Unknown`은 지금처럼 받고 로그만 남긴다. | 위 「이유」에 함께 적힘 |
