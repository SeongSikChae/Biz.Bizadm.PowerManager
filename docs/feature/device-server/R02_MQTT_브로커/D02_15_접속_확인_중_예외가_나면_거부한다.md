# D02_15 접속 확인 중 예외가 나면 거부한다

## 상황

접속 확인 중 예외(예: SQLite 조회 실패)가 나면 받을지 거부할지. 지금은 Error 로그만 남기고 접속을 받는다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C4(`docs/specs/mqtt-connect-auth/`(지움. `15dc357`에 있음)), 짝 태스크 `T02_09`

## 결정

- A. 거부(fail-closed): Error 로그를 남기고 접속을 거부한다. DB 장애 동안 장치는 접속하지 못하고 다시 접속을 시도한다.

## 이유

- A는 장애를 틈타 인증 없이 접속되는 일을 막는다. B는 가용성은 높지만 장애 때 인증이 꺼지므로 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 허용(fail-open): 지금처럼 Error 로그만 남기고 접속을 받는다. DB 장애 동안 인증 없이 접속된다. | 위 「이유」에 함께 적힘 |
