## 위험

- 등록하지 않은 실장비와 시험 클라이언트는 배포 즉시 접속하지 못한다(의도한 결과).

- MQTTnet의 반환 코드 변환(4, 3)은 패키지 소스로 확인하지 못해 원시 TCP CONNACK 바이트로 테스트했다.
