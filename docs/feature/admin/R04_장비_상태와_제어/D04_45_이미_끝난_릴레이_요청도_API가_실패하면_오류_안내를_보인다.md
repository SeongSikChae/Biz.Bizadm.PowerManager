# D04_45 이미 끝난 릴레이 요청도 API가 실패하면 오류 안내를 보인다

## 상황

구현 후 검토 1회차 지적 2. 켜진 상태에서 끄기 확인 창을 연 사이 꺼짐 보고가 오고 "끄기"를 누르면, 요청은 나가지만 이미 보낸 값과 같은 상태라 진행 중이 바로 끝나고, 그 뒤 API가 실패해도 오류 안내가 나오지 않는다(C22와 다름).

- 정한 단계: 구현
- 관련: 옛 작업 스펙의 `RelayControl.tsx`, `RelayControl.test.tsx`(spec.md·plan.md는 바꾸지 않음)(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 실패는 항상 보임: 진행 중 판정은 그대로 두고, 이미 끝난 요청이라도 API가 실패하면 오류 안내를 보인다. 새로 보낸 요청이 있으면 덮지 않는다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
