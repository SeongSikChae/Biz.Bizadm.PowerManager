# D04_56 성공 안내가 보이는 동안 "설정을 불러오는 중"은 화면에서만 숨긴다

## 상황

plan 검토 1회차 지적 1. 폭 390px에서 설정 응답 전에 예약 삭제가 성공하면 버튼 줄에 "저장", "삭제", "장비에 보냈습니다", "설정을 불러오는 중"이 함께 놓여(약 336px, 쓸 수 있는 폭 310px) 줄이 바뀌고, 예약 묶음 높이가 28px 늘었다가 응답 뒤 줄어든다. spec C2와 device-control R21에 어긋난다.

- 정한 단계: plan
- 관련: 옛 작업 스펙의 plan.md 인터페이스·데이터, 검증 전략(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 하나만 보이게 함: 성공 안내가 보이는 동안 "설정을 불러오는 중"을 화면에서만 숨긴다(`sr-only`, 읽기 프로그램에는 남음).

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 성공 안내를 버튼 줄 위로: 성공 안내를 실패 안내처럼 버튼 줄 위에 보인다. | 사용자가 말하지 않음 |
