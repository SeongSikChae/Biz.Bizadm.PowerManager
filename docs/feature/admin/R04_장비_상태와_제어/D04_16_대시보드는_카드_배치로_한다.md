# D04_16 대시보드는 카드 배치로 한다

## 상황

대시보드에서 장비를 어떤 형태로 늘어놓을지. 시안(저장소 밖, 2026-11-22)에 두 안을 만들어 보였다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 카드: 장비마다 카드 하나. 전력을 크게, 전압·전류·역률을 그 아래에 두고, 카드 아래쪽에 릴레이 스위치와 "제어" 버튼을 둔다. 좁은 화면에서는 한 줄로 쌓인다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 표: 장비 한 대가 한 줄. 상태, MAC, 모델, 전력, 전압, 전류, 역률, 마지막 보고, 릴레이 스위치, "제어" 버튼 순서. 좁은 화면에서는 표 안에서 가로 스크롤한다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D008에서 옮겼다(2026-11-23).
