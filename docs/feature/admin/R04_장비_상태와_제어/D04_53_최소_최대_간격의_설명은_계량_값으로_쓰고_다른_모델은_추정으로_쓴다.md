# D04_53 최소·최대 간격의 설명은 "계량 값"으로 쓰고 다른 모델은 추정으로 쓴다

## 상황

spec 검토 1회차 지적 2. C6의 최소·최대 간격 설명이 모델과 관계없이 단정이었다. M130-W는 보고 조건의 의미가 추정이고(`docs/reference/mqtt-device-control.md` 2절), B540에서 본 것도 `sid` `1` 보고의 간격뿐이며 릴레이 변경은 `sid` `2`로 따로 보고되는데(3.4) "값이 바뀌어도 이 시간 안에는 다시 보고하지 않습니다"라고 했다. 다른 모델에서 이름과 설명이 어긋나고 릴레이 표시도 늦어진다고 오해할 수 있다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C6(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 계량 값, 모델별 문구: "값"을 "계량 값"으로 바꾸고 B540이 아니면 "…것으로 추정합니다"를 쓴다. 변화 기준도 "계량 값이 이만큼 바뀌면 …"으로 맞춘다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 계량 값으로만 바꿈: 모델 구분은 이름의 "추정"에 맡기고 설명은 모든 모델이 같다. | 사용자가 말하지 않음 |
