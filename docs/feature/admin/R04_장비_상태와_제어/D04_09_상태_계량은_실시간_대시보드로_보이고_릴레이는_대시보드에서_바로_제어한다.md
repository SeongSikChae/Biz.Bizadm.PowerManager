# D04_09 상태·계량은 실시간 대시보드로 보이고 릴레이는 대시보드에서 바로 제어한다

## 상황

상태·계량 읽기와 릴레이 켜기/끄기를 어떤 화면에 둘지. 처음 제안은 장비 목록에서 장비를 골라 들어가는 장비 상세 화면에 "읽기" 버튼이 있는 상태·계량 카드와 릴레이 켜기·끄기 버튼을 두는 것이었다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- B. 대시보드: 장비 전체의 상태·계량을 한 화면에 실시간으로 보이고, 그 화면에서 릴레이를 바로 켜고 끈다.

## 이유

- 사용자가 "상태, 계량 정보는 대시보드 형태로 실시간으로 나오는 게 맞고, 릴레이 켜고 끄기는 대시보드에서 바로 하는 게 낫다"고 말함. A를 고르지 않은 이유는 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| --- | --- |
