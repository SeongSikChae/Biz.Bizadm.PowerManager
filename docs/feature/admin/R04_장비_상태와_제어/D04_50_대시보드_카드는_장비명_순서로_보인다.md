# D04_50 대시보드 카드는 장비명 순서로 보인다

## 상황

대시보드 카드 순서에 장비명을 쓸지. 지금은 MAC 오름차순이다. 장비 목록의 기본 정렬은 그대로 두고 검색에 이름을 더하는 것을 전제로 했다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 이름순, 없으면 뒤: 이름이 있는 장비를 이름 가나다순으로 먼저, 이름 없는 장비를 MAC 순으로 뒤에 보인다. 이름이 같으면 MAC 순이다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 지금처럼 MAC 순: 이름과 관계없이 MAC 오름차순을 유지한다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-name-and-units/decisions.md`(지움. `15dc357`에 있음) D004에서 옮겼다(2026-11-23).
