# D04_46 닫히는 확인 창을 다시 누른 것은 공통 확인 창에서 버린다

## 상황

구현 후 검토 2회차 지적 1. 확인 창은 닫히는 애니메이션 동안 남아 다시 누를 수 있어, "재부팅"을 더블 클릭하면 재부팅 다음에 전원 재투입이 나가고 다른 확인 창은 같은 명령이 두 번 나간다(C22·C25·C27과 다름).

- 정한 단계: 구현
- 관련: 옛 작업 스펙의 `ConfirmDialog.tsx`, `DeviceControlPage.test.tsx`(spec.md·plan.md는 바꾸지 않음)(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 확인 창에서 막음: 공통 `ConfirmDialog`가 열려 있을 때의 클릭만 실행한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 확인 창과 각 묶음에서 막음: A에 더해 각 실행 함수에도 검사를 넣고, 닫히는 동안 창의 글자를 유지한다. | 사용자가 말하지 않음 |
