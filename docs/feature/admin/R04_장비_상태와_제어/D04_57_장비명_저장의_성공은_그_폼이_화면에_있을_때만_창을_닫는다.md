# D04_57 장비명 저장의 성공은 그 폼이 화면에 있을 때만 창을 닫는다

## 상황

구현 후 검토 1회차 지적 1. 장비명을 저장하는 동안 "취소"나 Esc로 닫고 "이름 변경"을 다시 열면, 앞 요청이 성공한 순간 다시 연 창이 닫히고 쓰던 이름이 안내 없이 사라졌다. 앞 폼이 사라진 뒤에도 `onSaved`가 부모의 창을 닫기 때문이다. 응답이 늦을 때 입력을 잃는다.

- 정한 단계: 구현
- 관련: 옛 작업 스펙의 DeviceNameDialog.tsx(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 폼이 있을 때만 닫음: 저장을 보낸 폼이 아직 화면에 있을 때만 성공 뒤 창을 닫는다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 보내는 동안 닫지 못함: 저장 응답이 올 때까지 "취소"와 Esc를 막는다. | 사용자가 말하지 않음 |
