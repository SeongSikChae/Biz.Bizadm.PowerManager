# D04_25 예약의 N 단위가 초로 추정이라는 것은 「근거의 한계」에만 밝힌다

## 상황

spec 검토 3회차 전체 점검 1. spec은 예약의 N을 "다시 켤 때까지의 초"로 단정했는데, 근거 문서 3.3은 자동 복구 시간을 "초 단위로 추정한다"고 적었다. 전원 재투입 값(`/100/0/68`)은 단위 미확인으로 다루고 화면에 추정 안내를 두어, 같은 종류의 두 값의 표기 수준이 달랐다. 예약 쪽은 "현재 초가 항목의 초에 N을 더한 값과 같을 때 켠다"는 비교가 디컴파일로 관찰돼 근거가 더 강하다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「근거의 한계」 예약 항목(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 「근거의 한계」에 명시: 예약 항목에 "N의 단위는 초로 추정한다"를 더하고, 완료 조건의 "초"와 화면은 그대로 둔다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
