# D04_38 예약 시각 전후의 보고 관찰을 동작한 예약으로 한정한다

## 상황

spec 검토 6회차 지적 1(회귀). 「확정한 결정」의 "같은 날 예약 시각 전후에는 다시 켤 때의 보고만 왔고 꺼짐 보고는 오지 않았다"가 어느 예약인지 한정하지 않아 그날의 모든 예약에 대한 관찰로 읽힌다. 로그에서 맞는 것은 16:00 예약(`0200000`)뿐이고, C31의 "예약 시각 전후의 보고"도 이 문장을 가리킨다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「확정한 결정」(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 21행만 한정: 「확정한 결정」의 문장을 동작한 예약(`0200000`, 16:00:00)과 한 번 관찰로 한정한다. C31은 이 문장을 가리키므로 그대로 둔다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
