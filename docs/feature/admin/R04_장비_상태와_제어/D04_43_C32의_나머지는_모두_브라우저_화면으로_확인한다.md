# D04_43 C32의 나머지는 모두 브라우저 화면으로 확인한다

## 상황

spec 검토 7회차 지적 3. C32의 안내 글자 크기, 입력 칸 폭, 버튼 줄 자리, 성공 안내가 나타난 뒤의 높이가 C28의 확인 방법 어디에도 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C28, plan.md 검증 전략 C32(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 나머지는 모두 브라우저로: 테스트로 보는 것 말고는 C32 전부를 1440px·2000px·390px 브라우저 화면으로 확인한다고 적고, plan.md 검증 전략에 안내 글자 크기를 더한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 글자 크기 요구를 뺌: C32에서 같은 글자 크기 요구를 빼고 나머지만 C28에 더한다. | 사용자가 말하지 않음 |
