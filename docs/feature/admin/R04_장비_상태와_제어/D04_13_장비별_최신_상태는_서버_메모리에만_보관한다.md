# D04_13 장비별 최신 상태는 서버 메모리에만 보관한다

## 상황

장치 보고로 받은 최신 상태(릴레이, 계량 값, 온라인 여부)를 어디에 보관할지.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 서버 메모리: 서버를 다시 시작하면 사라지고, 다음 장치 보고로 다시 채워진다. DB 변경이 없다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. DB 저장: 서버를 다시 시작해도 마지막 값이 남는다. 테이블과 마이그레이션을 더한다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D005에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_02`의 「고칠 파일」을 본다.
