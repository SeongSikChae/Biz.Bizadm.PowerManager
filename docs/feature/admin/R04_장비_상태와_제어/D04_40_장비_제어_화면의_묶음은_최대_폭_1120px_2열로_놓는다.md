# D04_40 장비 제어 화면의 묶음은 최대 폭 1120px 2열로 놓는다

## 상황

사용자가 약 2000px 폭의 화면에서 장비 제어 화면이 "규격화 되지 않음"을 지적하고 고쳐야 한다고 했다. 묶음이 화면 폭에 따라 4개까지 한 줄로 늘어나고, 묶음 높이·입력 폭·버튼 위치와 종류·안내 위치가 서로 달랐다. 어느 안이든 입력은 같은 칸 폭, 안내는 제목 바로 아래, 버튼은 묶음 맨 아래 같은 줄, 보냈다는 안내는 버튼 옆(묶음 높이가 바뀌지 않게), 390px에서는 한 줄로 쌓는 것은 같다.

- 정한 단계: 구현
- 관련: 옛 작업 스펙의 spec.md C25·C28·C32, plan.md 바꿀 파일·결정·검증 전략, tasks.md 단계 5-2(T040)·단계 8(T041)(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 2열 고정: 본문 최대 폭 1120px, 왼쪽 정렬, 2열. 같은 줄의 묶음은 높이가 같다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

| C. 폭에 맞춰 2~4열, 높이만 통일: 화면을 다 쓰고 묶음 높이와 버튼 위치만 맞춘다. | 사용자가 말하지 않음 |
