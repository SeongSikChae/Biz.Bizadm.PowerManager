# D04_24 장치 메시지의 장비 판정은 장치 키 안 mac의 위치를 가리지 않는다

## 상황

`D04_22`(옛 D014) 대체(판정 방법만). spec 검토 2회차 지적 3. `D04_22`(옛 D014)는 장치 키의 "마지막 `-` 뒤 12자리"가 ClientId의 mac과 같을 때만 반영하게 했다. 그런데 B540 장치 키에서 mac이 마지막 요소라는 근거가 없다(`docs/reference/b540-mqtt-topic.md` 2절 "순서는 미확인", 4절. 회사-모델-MAC 순서는 M130-W에서만 관찰). 순서가 다르면 B540의 모든 메시지가 버려져 상태도 제어도 안 되고 B540 전용인 재부팅을 쓸 수 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 완료 조건 용어, 「근거의 한계」(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 위치를 가리지 않음: 토픽 장치 키를 `-`로 나눈 요소 가운데 ClientId의 mac과 같은 것(대소문자 무시)이 있으면 그 장비의 메시지로 본다. 「근거의 한계」에 B540 장치 키 순서 미확인을 적는다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 한계만 명시: 판정은 두고, 순서가 다르면 B540 메시지가 반영되지 않고 Warning 로그로 드러난다고 「근거의 한계」에 적는다. | 사용자가 말하지 않음 |

## 경위

- 앞 결정 `D04_22`(옛 D014)을 대신한다.
