# D04_12 릴레이 끄기에만 확인 창을 둔다

## 상황

대시보드에서 릴레이를 바로 제어할 때 실수로 전원을 내리는 것을 어떻게 막을지.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 끄기에만 확인 창: 끄기는 확인 창을 거치고, 켜기는 바로 실행한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 확인 창 없음: 켜기·끄기 모두 바로 실행한다. | 사용자가 말하지 않음 |
| C. 둘 다 확인 창: 켜기·끄기 모두 확인 창을 거친다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D004에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_02`의 「고칠 파일」을 본다.
