# D04_41 대기전력 차단 관찰을 spec과 근거 문서에 적는다

## 상황

spec 검토 7회차 지적 1. spec.md 「확정한 결정」과 근거 문서 3.4는 대기전력 차단 때의 보고를 미확인으로 적었으나, 2026-11-22 로그에 차단으로 꺼질 때의 보고(`/100/0/31` `false`·`/100/0/32` `1`)가 네 번 있고 B540 `1.01.34`의 코드(`0x4029b977`~`0x4029b9b3`)도 그때 보고한다. 기준 전력 `1.00`에는 장치가 `1.10`으로 응답했다. C31의 관찰 목록에 이 항목이 없어 C31만으로는 고쳐지지 않는다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「확정한 결정」·「근거의 한계」·C31, plan.md 바꿀 파일, tasks.md T041·T042(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. spec·근거 문서에 적음: 「확정한 결정」·「근거의 한계」·C31의 목록을 관찰에 맞추고, plan.md의 적을 절에 3.2를 더하며 근거 문서 작업(T042)을 더한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. spec만 고침: 「확정한 결정」만 관찰로 바꾸고 근거 문서는 그대로 둔다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D033에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_02`의 「고칠 파일」을 본다.
