# R04 장비 상태와 제어

## 목적

관리자가 장비의 지금 상태를 보고 장비 한 대를 원격으로 제어하려 한다. 서버는 장비별 최신 상태와 마지막으로 보낸 설정을 메모리에 두고, 관리 포트의 상태 조회·상태 스트림(SSE)·설정 조회·제어 API를 내준다. 장비 제어 화면(`/devices/{mac}`)은 장비명을 정하고 장비 한 대의 릴레이, 전원 재투입, 재부팅, 보고 조건, 대기전력 차단, 예약 전원 재투입을 제어한다.

용어: **mac**은 소문자 12자리 16진수다. **온라인**은 그 mac의 MQTT 클라이언트(ClientId `DAWONDNS-{mac}`)가 브로커에 접속해 있는 것이다. **제어 메시지**는 서버 → 장치 토픽(`device-server/R02-R2`)에 retain 없이 보내는 `{"sid":"<문자열>","msg":{"o":"<op>","e":[{"n":"<경로>","sv":"<값>"}]}}`이다. **장비의 메시지**는 장치 → 서버 토픽으로 온 메시지 가운데, 토픽 장치 키를 `-`로 나눈 요소 가운데 보낸 클라이언트 ClientId의 mac과 같은 것(대소문자 무시)이 있는 것이다. **근거 문서**는 `docs/reference/mqtt-device-control.md`다.
