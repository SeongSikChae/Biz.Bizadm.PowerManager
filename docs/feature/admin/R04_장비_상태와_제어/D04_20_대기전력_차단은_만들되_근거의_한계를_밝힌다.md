# D04_20 대기전력 차단은 만들되 근거의 한계를 밝힌다

## 상황

spec 검토 1회차 지적 6. 대기전력 차단 값의 범위(기준 전력 0.00~9999.99, 지연 0~9999)에 출처가 없었다. 근거 문서 3.2에서 `/100/0/40`~`42`의 의미는 추정이고 배율 상수는 미확인이며, 받아들이는 범위와 지연의 단위는 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「근거의 한계」, C11, C26(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 한계 명시: 범위가 서버가 정한 입력 제한임을 적고, 의미 추정·배율·단위 미확인을 「근거의 한계」와 화면 안내에 밝힌다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 범위에서 뺌: 대기전력 차단을 이번에 만들지 않는다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D012에서 옮겼다(2026-11-23).
