# D04_49 같은 장비명을 여러 장비에 쓸 수 있다

## 상황

장비명의 규칙. 앞뒤 공백을 없앤 뒤 1~30자, 줄바꿈·제어 문자는 받지 않는 것은 공통이고, 같은 이름을 두 장비에 쓸 수 있는지를 정한다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 중복 허용: 같은 이름을 여러 장비에 쓸 수 있고, 화면에는 이름과 함께 모델·MAC을 보여 구분한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 중복 금지: 다른 장비가 쓰는 이름(대소문자 무시)이면 409로 거부하고 입력 옆에 이유를 보이며 DB에 유일 조건을 둔다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-name-and-units/decisions.md`(지움. `15dc357`에 있음) D003에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_03`의 「고칠 파일」을 본다.
