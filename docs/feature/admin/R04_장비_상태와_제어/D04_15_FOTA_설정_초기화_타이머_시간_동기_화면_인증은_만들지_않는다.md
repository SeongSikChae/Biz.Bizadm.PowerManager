# D04_15 FOTA·설정 초기화·타이머·시간 동기 화면·인증은 만들지 않는다

## 상황

근거 문서(`docs/reference/mqtt-device-control.md` 2절)의 제어 항목 가운데 무엇을 화면과 기능으로 만들지.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 제안 범위: 상태·계량, 릴레이 켜기/끄기, 전원 재투입, 재부팅, 보고 조건, 대기전력 차단, 스케줄을 만든다. FOTA(`/5/0/1`), 설정 초기화·등록 해제(`drg`·`d`), 타이머(`/100/0/50`~`57`), 시간 동기 화면, 관리 화면 인증은 만들지 않는다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 범위 조정: 위 목록에서 더하거나 뺀다. | 사용자가 말하지 않음 |
