# D04_48 장비명은 장비 제어 화면 머리에서 정한다

## 상황

장비명을 어디에서 입력·수정·삭제할지. 장비에는 지금 이름이 없어 모델과 MAC으로만 구분한다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 장비 제어 화면 머리: 머리의 이름 옆 "이름 변경" 버튼으로 창을 열어 저장하고, 비워서 저장하면 이름을 지운다. 장비가 오프라인이어도 할 수 있다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 장비 목록: 장비 목록 표에 "이름" 열과 행마다 수정 버튼을 두고 같은 창으로 저장한다. | 사용자가 말하지 않음 |
| C. 둘 다: A와 B의 두 자리에서 모두 고친다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-name-and-units/decisions.md`(지움. `15dc357`에 있음) D002에서 옮겼다(2026-11-23).
