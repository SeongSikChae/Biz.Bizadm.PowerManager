# D04_52 추정한 단위는 장비 모델에 맞춰 "추정"을 붙인다

## 상황

확인한 단위와 추정한 단위를 어떻게 구분해 보일지. B540 `1.01.36` 실장비에서 보고 조건 5/30/1을 보낸 뒤 보고 간격이 5.22~5.28초(202회)와 30.72~31.13초(136회)에 모여(서버 로그, 2026-11-22) 최소·최대 간격은 약 1초 단위로 확인했다. 변화 기준 %, 기준 전력 W, 지연 초는 추정이고, M130-W는 값을 바꿔 확인한 적이 없다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 장비 모델에 맞춰: 확인한 단위는 단위만, 추정은 단위 뒤에 "추정"을 붙인다. B540이 아닌 모델에서는 모든 단위를 추정으로 보인다(예약의 시·분·초는 이름 자체가 단위라 그대로). 묶음 안내의 "값의 의미와 단위는 추정입니다"와 "전원 재투입 단위는 약 1초입니다(B540에서 확인)"는 뺀다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 모델과 관계없이 같게: 모든 모델에서 같은 문구를 쓰고, B540에서만 확인한 값은 "B540에서 확인"이라고 설명에 적는다. | 사용자가 말하지 않음 |
| C. 추정은 단위를 안 적음: 확인한 단위만 적고, 추정인 값은 단위 없이 "단위 미확인"이라고만 적는다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-name-and-units/decisions.md`(지움. `15dc357`에 있음) D006에서 옮겼다(2026-11-23).
