# D04_07 B540 현재 요일 저장 위치는 B540 `SetLocalAlramTime`을 디컴파일해 확인한 값으로 적는다

## 상황

구현 후 검토 2회차 참고 사항(검토자는 지적으로 세지 않음). 새 문서 3.3 `SetLocalAlramTime` 항목이 현재 요일 위치로 M130-W 오프셋 `ctx+0x2994`를 B540 절에 그대로 적었고, B540 `0x402c9b94`는 디컴파일하지 않아 관찰 근거가 없었다. 같은 절에 B540 현재 시각을 `ctx+0x29a1`~`0x29a3`으로 적어 절 안에서 모순이 보였다.

- 정한 단계: 구현
- 관련: 옛 작업 스펙의 mqtt-device-control.md 3.3 `SetLocalAlramTime`(`docs/specs/device-control-ref/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_01`

## 결정

- A. B540 디컴파일로 확인 후 고침: B540 `0x402c9b94`를 디컴파일해 저장 위치를 확인하고 3.3에 모델별 위치를 적는다.

## 이유

- A는 분석 서버 실행 한 번이면 되고 `D04_05`(옛 D005)와 같은 방침으로 B540 근거를 관찰로 남긴다. B는 비용 차이가 작은데 근거가 추정으로 남아 고르지 않았다. 고치지 않음은 B540 절 안의 모순이 남아 고르지 않았다. 확인 결과 B540은 `ctx+0x29a0`이었다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 추정으로 표기: 디컴파일 없이 B540은 기존 문서 「시간 동기」의 요일 비트 위치 `ctx+0x29a0`으로 추정한다고 적는다. | 위 「이유」에 함께 적힘 |
