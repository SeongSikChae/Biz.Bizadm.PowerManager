# D04_44 C32의 검증 항목을 채우고 열 최소 폭을 27rem으로 정한다

## 상황

plan 검토 8회차 지적 1. 검증 전략 C32가 1440px와 2000px의 열 수·묶음 폭이 서로 같은지만 보아, 2열·최대 1120px·왼쪽 맞춤·묶음 자리를 어겨도 통과한다. 지금 격자의 열 최소 폭 `22rem`을 두면 1120px 안에 3열이 된다. 성공 안내 뒤의 높이도 "저장"만 적어 전원 묶음이 빠진다.

- 정한 단계: plan
- 관련: 옛 작업 스펙의 plan.md 결정(장비 제어 화면 배치)·검증 전략 C32(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 검증과 열 폭을 적음: 검증 항목에 2열·묶음 자리·격자 폭 1120px·왼쪽 맞춤·네 묶음의 높이를 더하고, 결정에 열 최소 폭 `27rem`을 적는다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
