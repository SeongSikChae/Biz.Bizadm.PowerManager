# D04_30 기준 spec 머리말의 옛 서술도 이번 변경에 맞춘다(tasks만 고침)

## 상황

tasks 검토 1회차 지적 4. `docs/features/mqtt-broker.md`(지움. `15dc357`에 있음) 머리말의 "서버 → 장치 명령 발행(`MqttDeviceCommandPublisher`)은 껍데기다"와 `docs/features/device-list.md`(지움. `15dc357`에 있음) 머리말의 "관리 화면 `/`"가 이번 변경과 어긋나게 되는데, tasks.md T035·T037과 단계 7 체크포인트는 요구·이력·`파일:` 줄만 다뤘다.

- 정한 단계: tasks
- 관련: 옛 작업 스펙의 tasks.md T035, T037, 단계 7 체크포인트(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. tasks만 고침: T035·T037에 머리말 서술 수정을 더하고 단계 7 체크포인트에 머리말을 더한다. plan.md는 두 파일을 이미 바꿀 파일로 적었으므로 그대로 둔다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. plan도 고침: A에 더해 plan.md 문서 항목에 머리말을 적는다(확인받은 plan의 의도 변경). | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D022에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_02`의 「고칠 파일」을 본다.
