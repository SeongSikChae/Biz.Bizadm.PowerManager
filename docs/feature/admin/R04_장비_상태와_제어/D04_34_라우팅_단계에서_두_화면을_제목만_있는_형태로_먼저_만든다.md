# D04_34 라우팅 단계에서 두 화면을 제목만 있는 형태로 먼저 만든다

## 상황

plan 검토 6회차 뒤의 tasks 일관성 점검 2. tasks.md T028(단계 4)은 `/`와 `/devices/:mac` 경로를 만드는데, 그 경로가 가리킬 `DashboardPage`·`DeviceControlPage`는 단계 5의 T030·T032에서 만든다. 단계 4 체크포인트는 `npm run build` 통과인데 그때는 화면 파일이 없어 import가 되지 않는다.

- 정한 단계: tasks
- 관련: 옛 작업 스펙의 tasks.md T028(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 제목만 있는 화면 먼저: T028에서 두 화면 파일을 제목만 있는 형태로 만들고 T030·T032에서 내용을 채운다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. T028을 단계 5 끝으로 옮김: T028을 T032 뒤로 옮기고 단계 4 체크포인트의 `/devices` 확인을 단계 5로 옮긴다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D026에서 옮겼다(2026-11-23).
