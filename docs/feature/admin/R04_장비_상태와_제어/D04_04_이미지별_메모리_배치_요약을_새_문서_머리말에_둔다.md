# D04_04 이미지별 메모리 배치 요약을 새 문서 머리말에 둔다

## 상황

plan 검토 2회차 지적 1. spec C1은 "머리말에 … 이미지마다 메모리 배치(IROM·IRAM·DRAM 링크 주소)가 있다"고 하는데, plan 「인터페이스·데이터」 1절(머리말)에는 배치가 없고 2절 「분석 대상과 메모리 배치」에만 있었다. 검증 전략 C1도 "머리말·2절"을 읽어 2절에 있어도 통과로 봐, spec과 판정 기준이 어긋났다. C1을 글자 그대로 대조하면 미충족으로 판정될 수 있다.

- 정한 단계: plan
- 관련: 옛 작업 스펙의 plan.md 「인터페이스·데이터」 1·2절, 「검증 전략」 C1(`docs/specs/device-control-ref/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_01`

## 결정

- A. 머리말에 배치 요약: plan 1절(머리말)에 이미지마다 IROM·IRAM·DRAM 링크 주소와 길이 요약 표를 넣고, 2절은 `_1`·`_2` 관계·덤프 비교·주소 재사용 판단만 맡긴다. 검증 전략 C1도 머리말·2절로 나눠 고친다.

## 이유

- A는 비용이 B와 비슷하게 plan 두 곳이고, spec C1 문구와 그대로 맞아 판정에 해석이 필요 없다. B는 spec 문구와 다른 해석에 기대므로 고르지 않았다. 고치지 않음은 C1 미충족 판정 혼선이 남아 고르지 않았다.
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.
