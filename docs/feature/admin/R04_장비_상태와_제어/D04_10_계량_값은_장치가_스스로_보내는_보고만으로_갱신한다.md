# D04_10 계량 값은 장치가 스스로 보내는 보고만으로 갱신한다

## 상황

대시보드의 계량 값을 얼마나 자주 갱신할지. 장치는 보고 조건(최소 간격·최대 간격·변화 기준, `docs/reference/b540-mqtt-topic.md` 「오브젝트 99 리소스 처리」)에 따라서만 계량 값을 보고하므로, 보고 사이에는 값이 갱신되지 않는다. 릴레이 변경은 장치가 바로 알린다(`docs/reference/mqtt-device-control.md` 3.4).

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 장치 보고만 사용: 장치가 보내는 보고를 받는 대로 보인다. 더 자주 보려면 보고 조건 제어로 간격을 줄인다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 서버가 주기적으로 읽기: 대시보드를 보는 동안 서버가 일정 간격으로 `r` 메시지를 보내 값을 받는다. | 사용자가 말하지 않음 |
