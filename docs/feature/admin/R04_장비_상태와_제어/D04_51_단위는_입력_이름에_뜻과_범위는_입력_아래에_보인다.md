# D04_51 단위는 입력 이름에, 뜻과 범위는 입력 아래에 보인다

## 상황

입력마다 단위와 넣을 수 있는 범위를 어떤 모양으로 보일지. 지금은 단위가 거의 없고 범위는 잘못 넣고 저장해야 오류로만 보인다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 이름에 단위, 아래 설명: 입력 이름 뒤에 괄호로 단위를 적고, 입력 아래 작은 글자로 뜻과 범위를 항상 보인다. 오류가 있으면 설명 아래에 더 보인다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 입력 칸 안에 단위: 입력 칸 오른쪽 끝에 단위를 붙이고 범위는 빈 칸의 자리 표시글로 보인다. 값을 넣으면 범위가 사라진다. 뜻 설명은 묶음 안내에 모은다. | 사용자가 말하지 않음 |
| C. 도움말 아이콘: 단위는 이름에 적고 뜻과 범위는 이름 옆 아이콘을 눌러 본다. | 사용자가 말하지 않음 |
