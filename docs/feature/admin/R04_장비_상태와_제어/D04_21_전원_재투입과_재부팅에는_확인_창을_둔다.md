# D04_21 전원 재투입과 재부팅에는 확인 창을 둔다

## 상황

spec 검토 1회차 지적 9-1. 「확정한 결정」의 "릴레이 끄기에만 확인 창을 둔다(`D04_12`(옛 D004))"와 장비 제어 화면의 "전원 재투입과 재부팅은 확인 창을 거친다"가 문면상 어긋났다. `D04_12`(옛 D004)는 켜기·끄기 사이의 결정이었다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「확정한 결정」, C25(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 문장을 나눠 적음: 릴레이는 끄기에만 확인 창을 두고, 전원 재투입과 재부팅은 전원이 내려가는 동작이라 확인 창을 둔다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 확인 창을 뺌: 전원 재투입과 재부팅의 확인 창을 없앤다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D013에서 옮겼다(2026-11-23).

## 코드
