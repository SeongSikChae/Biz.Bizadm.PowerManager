## 위험

- `InjectApplicationMessage`가 전달 이벤트를 부른 뒤 돌아오는지 미확인이라 3초 기다림으로 덮었다.
- 같은 ClientId의 새 접속 때 `Takeover` 끊김 순서는 미확인이었다(테스트로 확인).
- 장치가 받는 요청 `sid` 길이는 미확인이라 짧은 10진 문자열을 쓴다.
- 장치의 `e`·`r` 응답 토픽은 추정이라 서버는 토픽 접미와 상관없이 `n`·`notify`를 상태로 쓴다.
- 개발 모드 SSE는 Vite 프록시를 지나 실시간 반영이 늦을 수 있다.
