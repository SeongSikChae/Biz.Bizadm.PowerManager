# D04_36 장치 시계 관찰을 B540으로 한정하고 근거 문서 두 곳에 적는다

## 상황

spec 검토 5회차 지적 1. spec.md는 장치 시계가 시간 동기 응답으로 맞춰진다고 모델 한정 없이 적고 현재 요일 쓰기(`/100/0/59`)를 빼는 근거로 썼다. 그러나 관찰은 B540 `1.01.36` 한 대이고, C31이 적으라는 2026-11-22 관찰에 시계가 없어 `docs/reference/mqtt-device-control.md` 6절·7절과 `docs/reference/b540-mqtt-topic.md` 4절이 미확인으로 남아 spec과 어긋난다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 「근거의 한계」·범위 밖·C31, plan.md 바꿀 파일(b540-mqtt-topic.md), tasks.md T033(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 한정하고 C31에 더함: 시계 문구를 B540 `1.01.36`으로 한정하고, C31의 관찰 목록에 장치 시계를 더하며 적는 곳에 `docs/reference/b540-mqtt-topic.md`를 더한다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 문구만 한정: 시계 문구만 한정하고 C31은 그대로 둔다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D028에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_02`의 「고칠 파일」을 본다.
