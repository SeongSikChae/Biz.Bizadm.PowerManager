# D04_22 장치 메시지는 ClientId의 mac과 토픽 장치 키의 mac이 같을 때만 반영한다

## 상황

spec 검토 1회차 지적 9-2. 상태 보고를 어느 장비의 것으로 볼지(토픽의 장치 키인지, 보낸 ClientId인지) spec에 없었다. 인증된 다른 장치가 남의 장치 키 토픽으로 보고하면 누구의 상태와 제어 토픽이 바뀌는지 정해지지 않았다. B540 장치 키의 3요소 순서도 미확인이다(`docs/reference/b540-mqtt-topic.md` 2절·4절).

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md 완료 조건 용어, C1, C3(`docs/specs/device-control/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_02`

## 결정

- A. 두 mac이 같을 때만: 보낸 ClientId의 mac과 토픽 장치 키의 mac(마지막 `-` 뒤)이 같을 때만 반영하고, 다르면 Warning 로그를 남기고 반영하지 않는다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 토픽 장치 키만: 토픽 장치 키의 mac으로만 귀속한다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-control/decisions.md`(지움. `15dc357`에 있음) D014에서 옮겼다(2026-11-23).
- 뒤에 `D04_24`(옛 D016)이 이 결정을 대신했다.
