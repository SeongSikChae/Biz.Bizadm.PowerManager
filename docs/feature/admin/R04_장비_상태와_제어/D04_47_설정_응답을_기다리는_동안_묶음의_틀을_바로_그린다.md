# D04_47 설정 응답을 기다리는 동안 묶음의 틀을 바로 그린다

## 상황

장비 제어 화면에 들어가 설정 응답을 기다리는 동안 설정 묶음 셋(보고 조건·대기전력 차단·예약 전원 재투입)을 어떻게 보일지. 지금은 셋을 회색 상자 둘로 통째로 바꿔 응답이 늦으면 화면이 멈춘 것처럼 보이고, 2열에서는 "전원" 묶음이 400px로 늘었다 268px로 줄어든다(1440px에서 측정).

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 틀을 바로 그림: 제목·안내·입력 칸·버튼을 바로 그리고 입력과 저장만 비활성으로 둔다. 값이 오면 채우고 활성으로 바꾼다. 회색 상자와 깜박임을 없앤다. 예약 "삭제"는 설정 값과 무관하므로 응답 전에도 제어 가능하면 누를 수 있다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. 회색 상자를 실제 배치로: 회색 상자를 셋으로 늘려 실제 묶음과 같은 자리·높이에 두고 깜박임을 없앤다. 응답이 올 때까지 내용은 보이지 않는다. | 사용자가 말하지 않음 |
| C. 앞서 받은 값 먼저: 이전에 받은 설정을 남겨 바로 보인 뒤 뒤에서 새로 읽는다. 처음 들어갈 때는 A처럼 틀을 바로 그린다. | 사용자가 말하지 않음 |
