# D04_55 확인 창과 이름 변경 창의 mac도 고정폭으로 보인다

## 상황

spec 검토 1회차 지적 5. C16의 "mac은 고정폭이다(확인 창 제외)"가 admin-ui R2("식별자 값(MAC 등)은 고정폭으로 표시한다", 예외 없음)와 어긋났다. 지금 `ConfirmDialog.tsx`는 mac을 고정폭 없이 보인다.

- 정한 단계: spec
- 관련: 옛 작업 스펙의 spec.md C16(`docs/specs/device-name-and-units/`(지움. `15dc357`에 있음)), 짝 태스크 `T04_03`

## 결정

- A. 확인 창도 고정폭: 예외를 빼고 확인 창과 이름 변경 창의 mac도 고정폭으로 보인다.

## 이유

- 사용자가 말하지 않음
- 옛 결정 기록을 옮긴 것이다. 옛 기록은 사용자가 직접 말한 이유와 에이전트의 추천 이유를 나눠 적지 않았다.

## 버린 안

| 안 | 버린 이유 |
| --- | --- |
| B. admin-ui R2에 예외: 확인 창 예외를 admin-ui R2에 적고 C21에도 적는다. | 사용자가 말하지 않음 |

## 경위

- 2026-11-22 옛 작업 `docs/specs/device-name-and-units/decisions.md`(지움. `15dc357`에 있음) D009에서 옮겼다(2026-11-23).

## 코드

- 옛 기록에 코드 위치가 없다. 짝 태스크 `T04_03`의 「고칠 파일」을 본다.
