# R01 관리 화면 틀

## 목적

관리 화면의 모든 화면이 같은 모양과 동작으로 보이게 하려 한다. 이 스펙은 관리 화면 전체가 따르는 디자인 기준과 앱 틀(사이드바·본문·메뉴·경로), 그리고 관리 API를 관리 포트에서만 받는 제한을 정한다. 각 화면은 이 기준 위에서 자기 내용을 정한다.

## 요구사항

| ID | 요구사항 | 상태 | 일감 |
| --- | --- | --- | --- |
| `R01-R1` | 관리 화면은 색·모서리 반경에 `src/index.css`의 shadcn 토큰(`radix-nova` 스타일, `neutral` 기본색, 라이트)만 쓴다. 화면 코드에 색 값을 직접 쓰지 않고 토큰 클래스(`bg-background`, `text-muted-foreground`, `border` 등)를 쓴다. 상태 표시(온라인)에는 상태용 색 토큰 `--success`(`--color-success`)를 쓴다. 다른 디자인 시스템이나 UI 라이브러리를 들이지 않는다. 다크 모드는 지원하지 않는다. | 반영 | #17, #28 |
| `R01-R2` | 관리 화면의 `--font-sans`는 `'Geist Variable', 'Noto Sans KR Variable', sans-serif`이며, 두 글꼴 모두 fontsource 패키지로 번들한다(사용자 PC 글꼴에 의존하지 않는다). 식별자 값(MAC 등)은 고정폭(`font-mono`)으로 표시한다. | 반영 | #17 |
| `R01-R3` | 앱 틀(`AppShell`)은 왼쪽 사이드바(제품명 "PowerManager", 메뉴, 현재 메뉴 `aria-current="page"`)와 오른쪽 본문(`main`)이다. 폭 1440px에서는 나란히, 둘이 한 줄에 들어가지 않는 폭(390px 등)에서는 사이드바가 본문 위로 쌓이며 페이지 가로 스크롤이 생기지 않는다. 화면이 없는 메뉴는 넣지 않는다. 화면 경로는 대시보드 `/`, 장비 목록 `/devices`, 장비 제어 `/devices/{mac}`이고, 메뉴는 "대시보드", "장비" 순서다. 장비 제어 화면에서는 "대시보드"가 현재 메뉴다. 주소를 직접 열거나 새로 고쳐도 그 화면이 열리고, 브라우저 뒤로 가기가 동작한다. | 반영 | #17, #28 |
| `R01-R4` | 관리 화면은 버튼·입력·표·스켈레톤·알림·카드·스위치·확인 창(alert-dialog)·입력 창(dialog)·레이블·체크박스에 `components.json` 설정으로 shadcn CLI가 추가한 `src/components/ui/` 부품을 쓴다. 넓은 표는 테두리 상자 안에서 가로 스크롤한다. 본문 머리는 제목(`h1`) + 보조 문구, 오른쪽에 주요 동작 버튼을 둔다. | 반영 | #17, #28, #32 |
| `R01-R5` | 처음 불러올 때 관리 화면은 결과와 같은 모양의 스켈레톤(`role="status"`와 이름)을 보이거나, 값이 없어도 그릴 수 있는 입력 묶음이면 스켈레톤 대신 비활성 틀을 바로 보이고 불러오는 중임을 글자(`role="status"`)로 알린다. 빈 목록·검색 결과 없음은 점선 테두리 안내(아이콘·제목·설명·필요하면 동작 버튼), 오류는 destructive 알림(`role="alert"`, 원인, "다시 시도")으로 보인다. 아이콘만 있는 버튼에는 `aria-label`, 장식 아이콘에는 `aria-hidden`을 붙이고, 모든 조작에 키보드 포커스 표시가 보인다. | 반영 | #17, #33 |
| `R01-R6` | 서버는 관리 API(`/api/admin/...`)에 `[AdminPortOnly]`를 붙인다. 연결이 들어온 로컬 포트가 관리 포트(`HttpPort`·`HttpsPort`)가 아니면 이 필터는 404 ProblemDetails로 끝낸다(Host 헤더와 무관, TLS 리다이렉트 기존 동작은 그대로). | 반영 | #17 |
