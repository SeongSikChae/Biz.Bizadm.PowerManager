# R00 원칙과 전체구조

## 목적

관리자가 브라우저로 PowerManager 서버에 붙은 장비를 보고 제어하려 한다. 관리 화면(`Biz.Bizadm.PowerManager.Client`)과 서버의 관리 API(`/api/admin/...`, 관리 포트에서만)를 묶은 영역이다. 관리 화면에는 아직 인증이 없으므로 관리 포트를 외부에 노출하지 않는 운영을 전제로 한다.

## 스펙 목록

| 번호 | 제목 | 한 줄 요약 |
| --- | --- | --- |
| `R01` | 관리 화면 틀 | 디자인 기준(토큰·글꼴·부품·상태 화면), 앱 틀과 메뉴, 관리 API 포트 제한 |
| `R02` | 장비 목록 | 등록 장비 목록 API와 검색·정렬·페이지가 있는 장비 목록 화면(`/devices`) |
| `R03` | 대시보드 | 장비 전체의 온라인·릴레이·계량 값을 실시간으로 보이고 릴레이를 켜고 끄는 첫 화면(`/`) |
| `R04` | 장비 상태와 제어 | 장비 상태 보관·상태 스트림·제어 API와 장비 한 대의 제어 화면(`/devices/{mac}`) |
