# B540 tisyn 시간 동기 응답(서버 → 장치) 분석 결과 기록 작업

형식: `- [ ] T001 [P] 설명 (파일 경로) — C번호`
`[P]`: 다른 파일을 고치고 끝나지 않은 작업에 의존하지 않아 다른 작업과 동시에 할 수 있음

## 단계 1: 기준점 재설정

- [x] T001 `git log`로 `80f299c` 이후 두 파일을 바꾼 새 커밋이 없는지 확인하고, 근거 문서와 기준 spec을 그림자 저장소 기준점 커밋에 `add -f` 후 `commit --amend --only`로 다시 담아 새 커밋 해시를 작업 문서 기준점 줄에 적는다 (docs/reference/b540-mqtt-topic.md, docs/features/mqtt-broker.md) — C5, C6

체크포인트: 그림자 저장소 `ls-files`에 두 파일이 있고, `git diff --cached <새 기준점>`과 작업 트리 diff가 둘 다 비어 있다. 작업 문서 기준점 줄이 새 해시다.
