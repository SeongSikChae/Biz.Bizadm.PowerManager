## 과거 인계 기록

### 새 에이전트 인계: B540-13부터 재개

> 아래는 이전 인계 시점의 이력이다. 새 에이전트는 위 B540-18 결과 검토까지 완료했으며 현재 상태는 문서 선두와 B540-19 절을 따른다. 당시의 결과 미수신·코드 미검토 상태를 현재 상태로 해석하지 않는다.

- 사용자 요청으로 현재 에이전트는 추가 분석·실행 안내를 중단한다. 별도 새 채팅/에이전트에서 이어간다. 자동으로 새 에이전트를 생성하거나 Linux에 접속한 것은 아니다.
- B540-12까지 결과 검토 완료. B540-13은 명령만 채팅에 제공했고 실행 여부·결과 미수신이다. 미실행으로 단정하거나 결과가 없는 상태를 실패로 해석하지 않는다. 사용자에게 먼저 확인하고 이미 실행했다면 재실행 대신 해당 산출물을 전달받는다.
- 기존 입력: B540-09 결과 폴더의 네 `.bin`; B540-11 결과 폴더의 부트 IRAM 추출본. 기대 크기·SHA-256 및 매핑은 위 단계에 기록했다.
- 도구: 작업 폴더 아래 xtensa-binutils 2.43.1의 objdump. 설치·빌드·Binwalk·전체 문자열 검사 반복 금지. 이전 EUID는 0이며 사용자 경로가 일반 사용자 실행을 뜻하지 않는다.
- 확인된 핵심: 헤더 크기 2 → 기준 0xfc → 제어 0xff000 첫 바이트 01 → fe 저장본 첫 8바이트 선택. fd/fe +8 차이는 이 범위 밖. 활성 앱 슬롯은 레코드 값·보조 주소 조립·로더 검사·test 경로 검토 전 미확인.
- B540-13 디코딩 범위와 로더 재배치 원리는 위 절을 따른다. 기존 부트 E9 추출본의 복사 소스 파일 오프셋 0x990 → 실행 주소 0x4010fc00, objdump adjust-vma 0x4010f270. 파일 전체의 실제 로드 주소로 취급하지 않는다. 새 raw 파일을 만들지 않는다.
- 이전 B540-13 채팅 명령의 오류 문구에 일본어 표현이 남아 있었다. 새 명령은 `{} 실행 실패, 종료 코드 {}` 등 한국어로 수정한다. 원시 로그는 변경하지 않는다.
- 후속 목표는 활성 슬롯/부트, 두 앱의 버전·코드/동작 차이, MQTT 연결·인증·토픽·메시지, TLS·인증서 검증, GPIO·릴레이·UART·계량·보정이다. 문자열·암호 상수만으로 구현 확정 금지.
- 별도 Rocky Linux에서 사용자 수동 실행, 단계 ID·목적·명령·부작용·필요 결과는 채팅에 직접 제공, 결과마다 이 문서 갱신, 모든 안내 한국어. SSH/Linux MCP 직접 접속 금지.
- 승인 밖 추가 영역 추출·설치·장치 실행·외부 접속은 범위/경로를 제시하고 승인받는다. 특히 원본 0xfc077 test-GPIO 필드는 아직 미검사. 현재 장치·기존 UART 로그·네트워크 캡처는 없다고 사용자가 답했다. 실제 런타임 검증을 완료했다고 표현하지 않는다.

### B540-13 재개: 실행 여부 확인 이력 — 이후 결과 검토 완료

> 아래는 재개 직후의 확인 이력이다. 이후 결과를 수신해 위 B540-13 결과 검토에 반영했으며 재실행하지 않았다.

- 새 에이전트가 2026-10-23 사용자 요청으로 문서 전체와 인계 절을 검토했다. B540-12까지 완료된 분석 및 기존 입력·도구·해시·매핑을 재사용한다.
- 실행 여부를 먼저 질문했고 사용자는 **이미 실행 완료 — 기존 결과를 전달하겠다**를 선택했다. 사용자 실행 완료 보고를 관찰했으며 실제 JSON·해시·디스어셈블·종료 코드는 아직 미수신이다. 성공 또는 입력 동일성 검증을 완료했다고 기록하지 않는다.
- **현재 액션 목적:** B540-13의 기존 산출물을 받아 선택 레코드와 정확한 코드 경계·로더를 분석한다. **명령:** 분석 재실행 명령 없음; 기존 결과만 전달받는다. **부작용:** 이 로컬 문서의 진행 상태만 갱신하며 Linux 접속·검사·파일 생성은 하지 않는다. **필요 결과:** 기존 결과 디렉터리 경로, 결과 JSON 전체 및 보고 SHA-256, 부분 디스어셈블/로더 전문, 종료 코드·오류 출력. 길면 기존 텍스트/JSON만 첨부하거나 순서대로 나누어 전달한다. 레코드 첫 8바이트도 전달 전에 검토하며 설정 `.bin` 원문은 요청하지 않는다.
- 이전 EUID 0을 유지해 설명하고 계정·소유권을 변경하지 않는다. 추가 영역 추출·설치·장치 실행·외부 접속은 별도 승인 대상이다. 원본 `0xfc077`과 활성 앱 슬롯은 여전히 미확인이다.
